# 设计空间扩大(用户指令, 即时生效)

网络结构本身也可以重新设计, 不必限于"添加模块"。可结合 CLE 共聚焦图像性质或实验
结果分析做结构级改动。车道划分相应扩展(仍以认领制防撞):
- zcode: 通用结构改动(空洞化/分辨率保持/池化方式等)
- Doubao: 训练维度+分辨率相关的结构
- Workbuddy: 频域/小波结构

## CLE 图像特性线索(zcode 分析, 供三家参考)
1. 灰度复制 3 通道(实测三通道统计完全相同) —— 通道维注意力无效的结构性原因
2. 内镜探头无固定方向 -> 图像无规范朝向, 旋转不变性值得结构级考虑
3. 判别依赖细胞/腺体级多尺度纹理, 深层连续 stride2 丢细节 —— 保分辨率结构
   (空洞化)已由 zcode 开跑(atrous4/atrous34)
4. 主要误差 Benign<->Malignant = 细粒度纹理差异, 浅层细节应保留至分类头
   (如 FPN 式多尺度特征融合进分类器)
