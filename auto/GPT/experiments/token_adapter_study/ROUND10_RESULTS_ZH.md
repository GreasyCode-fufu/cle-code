# 第十轮：CLE 全局上下文—局部 token 适配

结论：预定 CLE 候选没有带来已确认的新增结构收益。完整微调 DINOv2 在本轮开发集均值最高，但还需患者 OOF 复核，不能把这一训练方案当作新模块或独立确认的突破。

主候选相对冻结头 +0.99pt，患者配对95%区间 [-0.87,3.08]pt；相对 LoRA +0.33pt、普通局部适配器 +0.06pt、均值上下文 +0.34pt，区间都跨零。相对完整微调低1.70pt，区间同样跨零。五个主比较均未通过预注册的家族区间与幅度要求；不能按最高单种子、末轮或某个对照事后更换主终点。

本轮18个模型均完整训练60epoch；同全量train2386、完整val538、原224输入与增强，不使用等级/样本权重，不筛验证测试、不改标签，也没有评估test。LoRA/普通局部/上下文可训练参数约15万、差<3%，计数整网FLOPs差<1%。完整微调使用encoder1e-5/head1e-4，其余adapter/head1e-4；所有方案同AdamW、AMP和clip1。预算统计不等于严格延迟或分支算力匹配。

实际作用诊断显示，CLS候选使最终描述子相对L2变化约74.5%–96.0%；同checkpoint关闭适配器后22.1%–55.6%的验证预测改变。该分支确实学得动，不能归因于“机制从未打开”。关闭诊断也不能代替重训消融、证明定位了病灶，或把变化幅度当临床正确性。LoRA和普通局部适配器同样有明显实际作用，但未形成可靠结构优势。

完整微调最后训练准确率均值约99.99%，末轮验证均值比最佳低约2.72pt；最佳epoch为27/6/25（从0计数）。这说明 checkpoint 选择和泛化稳定性值得检验，不能由此直接确认标签噪声。所有验证成绩都用于开发与选择；患者bootstrap条件于已选模型，五比较家族修正也没有消除历轮反复使用开发集及训练波动的影响。

独立审计通过全部18个模型源码/权重SHA和任务签名、60行训练记录、最佳选择、完整538预测、患者隔离、有限权重、冻结源逐位不变（完整微调除外并记录漂移）、重新加载后的完整 on/off 推理、每图每block上下文有界值、五个重采样区间和所有权。初始化预检的键映射问题在任何正式训练前修复并重签，修订4c62b0d；没有改变前向或训练食谱。

结果提交47816ef。下一阶段固定完整微调食谱，沿用原15个患者fit/inner/outer划分，只新增15个DINOv2外层OOF模型；原固定val/test不参与。比较已有普通BN、冻结BN CNN和冻结DINO岭头的原患者OOF，以判断完整适配的信号能否支持后续CLE设计。该阶段不是新增结构试验，也不把本轮失败的主候选说成晋级。

本结构独立实现，LoRA/FiLM/局部适配属于成熟思想；不声称实现了原Convpass，也不承诺论文创新或录用。源码、完整配置、结构图、逐图预测、上下文诊断、训练曲线和独立审计均保留；大型权重留在服务器。
