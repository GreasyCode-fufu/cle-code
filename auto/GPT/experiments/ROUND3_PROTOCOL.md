# 第三轮预注册：保留分辨率的共享卷积双路径

## 为什么改变研究方向

前两轮均未检出稳定结构增益。第二轮完整模型验证均值 0.878639，GAP 基线 0.881958；去小波 0.882177，患者配对区间均跨零。继续堆叠池化注意力缺乏证据。

已有三个基线在完整验证集的平均错误率为 11.77%，32 张图在三个种子均错。按文件名亚型统计，dysplasia 90 张平均错误率 34.07%、17 张全错；cancer 66 张 6.57%；normal 159 张 1.68%。文件名不是新病理金标准，且 12 个验证文件名与当前类别目录不一致，因此这些统计只用于定位困难样本，不用于改标签、过滤或追加亚型监督。原始图像约 800×800，既有输入为 256 缩放/224 裁剪，layer4 输出 7×7；细节分辨率是待检验的假设，尚未被这些相关性证实。

## 固定实验与候选

仍用已冻结的患者映射、等级加权训练样本与权重，完整 val 538 张、39 组，种子 42/43/44；60 epoch、原 AdamW/退火/AMP/增强保持一致。复用已验证 GAP 基线预测。本轮不使用 test。

| 候选 | 作用 |
|---|---|
| dilated_control | 只保留 layer4 14×14，第一块 conv1 rate=1，后续 3×3 rate=2；取消首个 stride-2 和投影 stride。无新增参数。检验保留分辨率本身。 |
| fixed_dual | 标准 7×7 路径与 14×14 空洞路径共享卷积权重，独立高分辨率 BN；两个 GAP 描述子固定 0.5/0.5 融合。检验双路径本身。 |
| sk_dual | 相同双路径，用 sum-GAP → 512/64/1024 MLP → 分支 softmax 做逐通道路由，作为 SK 公式启发的匹配对照。并非原 SKNet 复现。 |
| cle_contrast | 在完全相同的参数和路径上，为路由描述子加入高分辨率相对局部对比度。检验对比度条件是否提供额外信息。 |
| cle_no_dilation | 与完整设计相同，但高分辨率路径的所有空洞率改为 1。检验高分辨率与感受野补偿的区别。 |
| static_dual | 相同双路径，使用训练得到的逐通道静态 softmax，而非逐图像 MLP 路由。检验样本适应性是否必要。 |

共 6×3=18 次训练，并发 2，每进程 CPU 线程 2。所有卷积权重来自同一原始预训练 ResNet34，新增 MLP 最后一层置零使初始路由为 0.5/0.5；两条路径都直接参与输出。每个种子的原分类头与对应基线完全一致。双路径只复制 BN，不复制卷积；单路径控制直接使用原 BN。

令高、低分辨率描述子为 h、l，高分辨率特征为 H。相对局部对比度为 r=clip(mean_abs(H−avgpool3(H))/(abs(h)+1e-4),0,2)。完整路由输入 (h+l)·(1+0.5r)，匹配 SK 对照输入 h+l；二者 MLP、参数数量与卷积/矩阵乘法预算相同。r 只是特征统计，不是病变、质量或标签正确性的定义。softmax 权重取正且和为 1。

## 预检查与分析判据

训练前检验共享功能卷积与独立修改的 nn.Conv2d 参考在前向和梯度上相符；配对初始化、关闭新增路径与原主干逐位一致；真实训练图 AMP 反向传播；共享卷积、独立高分辨率 BN、初始 0.5 路由的末层梯度；14×14/7×7 尺寸；完整模型与 SK 对照参数相同，计数的卷积/矩阵乘法 FLOPs 差异小于 1%。FLOPs 不涵盖全部池化/归一化/逐元素开销，不宣称零推理成本。

主对照为完整设计分别相对 GAP、dilated_control、fixed_dual、sk_dual。报告三个种子的全部分数、均值/标准差、恶性类 F1、完整逐图预测、患者分组配对 bootstrap 20,000 次区间、参数和计算量。其余是预注册机制消融。相同 checkpoint 关闭路径只诊断实际作用，不能替代重训练对照。

强晋级信号：完整模型相对 GAP 三个种子均正、均值至少 +1.0 个百分点、患者配对区间下界大于 0；相对固定融合和匹配 SK 对照的均值均至少 +0.5 个百分点且区间下界大于 0。较弱信号仍如实保存，不宣称结构收益已获确认。开发集已重复使用，区间以拟合模型为条件，未校正模型选择/多重比较；即使通过晋级条件也需要独立患者级确认。严格外层确认必须在外层训练折内重新分级，或使用独立分级器。不得使用现有 test 选择候选或阈值。
