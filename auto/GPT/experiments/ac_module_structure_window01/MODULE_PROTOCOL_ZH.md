# 共享模块与CLE方向机制正式预注册

本轮属于新窗口持续研究，固定B0仍为按开发集预先选定的ConvNeXt-Tiny、resize256/crop224。不降低、不事后替换baseline。此前DINO、CNN资格、几何结构的有效完整训练不重复。所有训练从同一公开ImageNet权重和对应seed的同一个三类分类头开始；不从已训练B0热启动。

人类已明确更新评价流程：train训练→val选权重→test测试→根据test反馈设计下一方法。test属于适应性开发反馈，不能称独立泛化验证。历史test已被查看，A–C清单构建使用过其标签；A/B/C等级是模型一致性代理，不证明医生标签全部正确。患者条件bootstrap不消除结构选择偏差。

数据固定：train2077图/182患者、val427/39、test576/41；原split患者互斥、标签、清单、等级、阈值均不改。物理3595缓存只按授权索引读取；每epoch实际训练2077个唯一索引及集合SHA写日志。共享模块库只读，原文件逐字节复制并记录SHA；历史冻结源码/权重不覆盖。

## 机制与首轮必要对照

|arm|固定实施|为什么适合CLE（待验证假设）|差异与对照|
|---|---|---|---|
|wtconv|ConvNeXt阶段2和3末块DW7换成Haar WTConv，kernel7、两级，原DW对象和参数保留；原算法base_scale1、wavelet_scale0.1|将细纹理与较大组织形态的尺度信息联系起来；不是预言有效|算子保持原方法；相同B0预算/配对seed；若有稳定收益，增加只空间分支/单级或等参数空间卷积重训对照|
|simam|阶段3输出后，原官方特征输出公式，lambda1e-4；将共享PSAA gate乘回输入|局部响应与通道空间方差相关，可能突出形态不均匀区域|零新增参数，与B0比较；不是原论文完整网络复现；若有效，测试同位置非自适应缩放及去空间差异重训|
|eca|阶段4输出后，自适应k=5、gamma2、b1|细微形态的通道组合可能比增加大骨干更经济|共享实现与官方显式k5数值等价；5参数；若有效，检验打乱通道/固定通道权重重训|
|ema|阶段3输出后，384通道、官方factor32|兼顾轴向上下文与局部3x3特征，检验CLE网状结构的空间交互|共享默认factor8改为官方factor32，公式不变；1488参数；若有效，去交叉空间或去轴向路径重训|
|c4_moments|stride4 stem保留原0度输出，加共享旋转核的4方向均值/标准差，经零初始化1x1投影残差；+18528参数|此前成熟4视图推理有test反馈收益，探索能否用约2.3%额外卷积量学习方向鲁棒性|新增代码，不宣称整体严格旋转等变；与B0及下述成熟C4训练增强比较；若有效，做mean_only/random_moments/drop-one等必要重训|
|c4_aug|原B0，原训练增强后每图再随机四分之一周旋转一次，独立RNG；每epoch仍2077张|检验新增方向分支的收益是否仅来自成熟方向增强|无新增参数，不借用C4推理的4倍前向预算；与c4_moments相同训练总epoch|

四类共享模块机制不同，先比较独立机制，不枚举全部425个库文件或无限近似组合。原论文完整网络的训练配方、ImageNet论文成绩不冒充本CLE插入实验的成绩。模块有效不自动等于SCI创新；先保留有证据的机制，再围绕互补假设新增1–2项设计，以累计及去一重训验证。

六个arm×seed45/46/47，共18项新训练。每项60epoch、batch32、AdamW decay0.05、cosine至0、梯度裁剪1、动态FP16 AMP。原encoder参数lr1e-5，分类头及新增参数lr1e-4。原RGB训练变换、stochastic depth0.1不变；c4_aug只新增明确注册的独立RNG四分之一周旋转。各模型构造不改变基础随机数状态。

所有checkpoint只按原始0度val macroF1的最早最大值选择；不根据test或C4 val换权重。三个seed完整完成并注册checkpoint SHA后，该方法统一做576张test的原单视图与固定四视图概率等权平均；两种推理均报告，不只选高者。全部seed与平均差保留。参照包括冻结B0原单视图、同C4的B0、原DINO及其C4、SwinC4。Swin和C4路径曾使用test反馈筛选，明确披露。

主要指标macroF1；同时记录accuracy、恶性类别1召回、患者等权准确率、逐seed混淆矩阵、参数及计算成本。数值门槛：对固定B0的三seed平均F1差严格大于0.015，三个seed均正，20,000次患者配对bootstrap条件95%下界正；并逐项披露同推理预算强参照的结果。不得将对失败结构的改善当成达标，不得将条件区间称为独立确认。

## 训练前审计及资源规则

先提交本协议、差异审计、源码、config、jobs。CPU预检核验共享/官方算子输出和梯度、Haar独立NumPy计算、参数及随机状态。之后真实batch32 CUDA AMP两步有限梯度、原B0全部3seed/427图概率重建、数据边界/源权重SHA核验；通过再训练。

当前旧几何流水线有效模型继续完成，不杀进程、不重复训练。其GPU活跃区间98–100%、并发实测更慢时，先CPU准备本轮，再自动衔接。每类模块各实测单任务/并发吞吐，选达到最佳97%的最小并发数，显存至少余6GiB；只在实际吞吐提高且资源允许时增并发。记录GPU计算/显存、CPU总/各核、iowait、RAM、diskstats、DataLoader等待、样本/秒及耗时。启动/退出时间的低GPU不冒充有效kernel段低利用率，不制造填卡训练。

逐方法独立核验60个epoch、真实2077训练索引、最早val最佳checkpoint、有限权重、源/权重SHA；以独立中心裁剪原始缓存路径复算427val和576test，另从独立TestData路径复算所有4方向概率。故障只修故障环节；完整checkpoint存在时优先补推理/审计。结果、阴性、日志、预测及审计Git提交并保持login所有权。

普通运行与阴性保持安静。研究继续，不因本轮结束而把总体目标标为完成；有真实障碍才如实记录，不保证达标、创新或录用。
