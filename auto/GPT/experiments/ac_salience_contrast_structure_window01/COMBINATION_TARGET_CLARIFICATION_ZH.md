# 组合目标与验证约定

本约定记录用户在2026-10-25进一步明确的研究目标；它适用于后续研究解释与设计，不改写历史预注册、source/config、数据或已完成结果。

最终目标是将2–3个互补的网络优化设计组合后，相对固定B0取得累计超过1.5个百分点的宏F1增益。不是要求每一个单独设计分别超过1.5。沿用既有严格数值计算，不舍入、挑seed或事后放宽阈值。

单点主要检验对已有工作机制的新增贡献、三seed方向与不确定性、参数及实际计算成本，以及与成熟控制的差异。有可信的小幅增量可以保留到下一累计组合；未单独达到1.5不作为淘汰理由。探索性信号与已确认组件继续区分，区间跨0不包装为确认收益，成熟模块组合不自动称创新。

原CNN方向矩继续作为保留主线。当前单视图相对B0平均增加0.892207个百分点，三seed方向正；四旋转推理相对B0增加1.476485个百分点。后者是当前观测值，严格不足1.5并不意味着方向矩应停止探索。方向矩相对普通旋转增强的优势尚未确认，不能据此直接宣称独立创新。

累计验证按保留机制M → M+A → M+A+B展开，配合真实重训的去一消融和成熟控制。保留完整有效结果，不重复训练已有效完成的旧模型；数据标签、等级、阈值、患者split、采样与固定B0不变。原Q/M相同recipe与公开起点预算继续执行。

C4属于四次前向的成熟推理策略，单列报告计算成本和同推理预算参照，不计作网络结构的第二或第三个创新点。最终组合同时报告单视图与C4，不能把主干预算或成熟TTA收益归因新增结构。

历史冻结文件中每个方案的numerical_gate和严格3/200计算保留为当时的数值审计字段；它们不再被解释为“每个单点必须达到的研究准入门槛”。当前已登记15模型队列和全部对照继续，不因本次澄清中止或改源。后续完整报告附本约定解释判据对象。

执行train训练→val最早最佳选权重→test→test反馈下一设计。全部test为自适应内部开发，患者bootstrap只是条件区间，不校正选择偏差，不称独立泛化或外部验证。整体研究继续；2–3个设计在验证前仍为候选机制，不预先承诺SCI新颖、提点或录用。
