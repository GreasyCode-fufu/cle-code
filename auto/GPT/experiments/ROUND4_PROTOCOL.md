# 第四轮预注册：同源全局—局部多视图 CLE 分类

## 依据与明确的不确定性

前三轮 54 次结构训练没有检出稳定收益。第三轮验证均值：完整设计 0.879506、GAP 0.881958、匹配 SK 0.881109，患者差异区间均跨零。固定模型的输入尺度诊断出现明显退化：GAP 从 224 的 0.88196 降至 336 的 0.77251、448 的 0.46731；逐张复核 538 张原尺度输入与冻结缓存逐位一致。这说明现有拟合模型的尺度敏感性，不估计高分辨率重新训练的效果。

本轮停止改动同一 224 图像上的卷积模块，直接检验输入信息与尺度联合学习：是否需要更细的原始像素，以及条件跨视图聚合是否优于普通聚合。细节并不等同于干净数据，也不预设高分辨率会更好。

## 同源输入与控制

仅将原 train+val 共 2924 张图预缓存为 PIL RGB 512×512 BILINEAR，保存 SHA256，排除 test。所有新模型共享同一 512→448 输入，训练 H/V 翻转、旋转 ±15°、随机 448 裁剪，验证中心 448 裁剪。其余优化器、60 epoch、批量 32、AMP、种子 42/43/44、患者映射和等级加权均保持既定方案。

| 方案 | 作用 |
|---|---|
| global224 | 将同一 448 视野用张量双线性抗锯齿下采样至 224，仅训练全局 ResNet34。这是主要基线。 |
| single448 | 直接在 448 输入上重新训练标准 ResNet34。检验高分辨率输入本身。 |
| tile_fixed | 一张全局 224 加同一 448 视野的四张非重叠 224 局部图；固定 0.75 全局 + 0.25 局部平均。检验信息与多视图本身。 |
| tile_attention | 同样五视图，普通 gated-MIL 式局部注意力和可学融合，作为参数/卷积预算匹配对照。 |
| tile_context | 用全局描述子作为 query，四个局部描述子作为 key/value，余弦兼容度驱动局部选择，再与全局融合。 |
| tile_no_context | 完整设计的 query 改为局部描述子均值，其余相同。检验全局条件是否必要。 |

共 18 次训练。原先 256/224 的 0.881958 基线只作背景参考；不能直接把新预处理的收益归因于网络机制。主要配对比较为完整设计相对新 global224、single448、tile_fixed、tile_attention。

## 共享网络与边界

全局与四局部视图共享全部 ResNet34 卷积和原分类头，局部使用独立复制的 BN 统计与仿射参数，避免不同图像尺度混合更新同一 BN。只有图像级分类损失，不把图像标签复制为每张局部图的独立监督，不使用亚型、患者 ID 或等级作为推理输入。

局部注意力对四图归一化。完整设计将 query/key 投影到 64 维，采用 4×余弦相似度并 softmax。对照为两个 512→64 投影的 tanh/sigmoid 门控及标量打分，打分经 4×tanh 有界。两者保留相同融合 MLP，新增参数与计数卷积/矩阵乘法 FLOPs 差异须小于 1%。这比较两种聚合器，不是声称完整复现原论文模块。

融合采用 z=(1−α)g+αΣaᵢlᵢ，α=0.5·sigmoid(MLP(g+mean(l)))，初始 α=0.25，至少保留一半全局描述子。固定对照也从 0.25 局部权重起步。局部分支直接参与输出，注意力不靠零初始化旁路启用。保存逐图四个局部权重和分支关闭诊断，但这些权重不是病灶标注。

## 预检查、预算与晋级

检查：完整高分辨率缓存 SHA256 与非 test 样本范围；四张局部图可以原位精确拼回输入；同种子 canonical 原主干/分类头逐位一致；局部关闭与同源全局主干逐位一致；真实训练图 AMP 反向传播；全局及局部描述子、共享卷积、各域 BN、注意力 query/key 有非零有限梯度；BN 统计独立；注意力归一化；全局权重下界；参数/计数 FLOPs 匹配；实测峰值显存能容纳两个并发任务并保留余量。实际计算、显存均报告，不宣称零推理成本或优于标准 448 的计算效率。

强晋级要求：完整设计相对新 global224 三种子均正、均值至少 +1.0 个百分点且患者配对区间下界大于 0；相对固定融合和普通注意力均值各至少 +0.5 个百分点且区间下界大于 0；相对标准 single448 的均值为正，避免把原始分辨率收益误归为跨视图机制。较弱信号保留，不宣称证实。完整报告 3 种子、完整 val 538 张/39 患者组、20,000 次患者配对 bootstrap、恶性类指标、计算/参数/显存及消融。

开发集反复使用，区间以训练好的模型为条件，未校正模型选择和多重比较。即使晋级，也需独立患者级确认以及数据×结构对照；严格外层 CV 的等级必须在外层训练折内部重算或用独立分级器。本轮不评估、不筛选 test，不改标签。
