# 第九阶段：冻结预训练表征的患者 OOF 诊断

结论：DINOv2 的冻结表征明显优于冻结 ImageNet ResNet34，但尚未可靠超过既有的微调 CNN。因此本轮预注册的完整跟进条件没有通过，不能称为新的 CLE 网络突破，也不能据此认定标签噪声是主要瓶颈。

| 方案 | 三次患者划分 OOF macro-F1 均值 | 恶性召回均值 |
| --- | ---: | ---: |
| 冻结 ImageNet ResNet34 GAP | 0.840943 | 0.683806 |
| 冻结 DINOv2 CLS | 0.866158 | 0.728723 |
| 冻结 DINOv2 patch 均值 | 0.871247 | 0.729905 |
| 冻结 DINOv2 CLS + 均值（预定主方案） | 0.873057 | 0.734634 |
| 原普通 BN 微调 CNN + GAP 岭头 | 0.862553 | 0.680851 |
| 原冻结 BN 微调 CNN + GAP 岭头 | 0.871950 | 0.715130 |

主方案对冻结 ImageNet ResNet34 增加 3.21pt，185 患者配对 95% 区间为 [1.69,4.91]pt，五比较 Bonferroni 家族区间为 [1.23,5.49]pt。对普通 BN 微调参考增加 1.05pt，但 95% 区间为 [-0.54,2.62]pt；对冻结 BN 微调参考仅增加 0.11pt，95% 区间 [-1.75,2.18]pt。主方案需同时超过三个对照的预注册门槛，结果为 false；不能只挑最容易超过的冻结基线来宣称整体胜出。

本阶段零新增神经网络训练。两个公开预训练主干只各提取一次原 train 的 2386 张特征，沿用原 15 个患者 fit/inner/outer 划分。每折仅在 fit 患者估计标准化和拟合固定 alpha=1 岭头，共 60 次解析拟合，另复制六份已有 OOF 参考。三个 seed 表示患者划分重复，不代表三个独立预训练初始化。原固定 val/test 没有参与本阶段拟合或评分。

独立审计核验了权重和运行库 SHA、冻结特征 2386×1280、15 个原始患者三集合、60 个 fit-only 变换与岭正规方程、保存头的逐图预测、六份原参考、18 份完整 OOF 和所有患者重采样区间。审计结果为 passed。岭 softmax 分数未经校准，不能充当临床置信度或人工确认。

DINOv2 采用官方公开权重和 Apache2.0 许可，通过 timm1.0.27 port 加载；位置插值与官方 offset 插值存在已记录差异。两主干的预训练数据、架构、精度、特征维数和计算不同，因此不能把差值归因于单一的自监督机制。公开预训练数据与研究数据是否重叠未完成审计。本轮是内部条件区间，未充分涵盖重叠训练折、重复开发选择和训练波动。

结果提交 fe007f2。下一轮作为新的探索性假设，检验冻结表征上的有限 CLE 域适配；设冻结头、完整微调、LoRA 和普通局部适配器对照，再检验全局上下文调节局部 token 的候选结构。该安排不等于本轮已达到强跟进标准；新增结构仍须公平消融和患者级确认，不承诺创新或论文录用。
