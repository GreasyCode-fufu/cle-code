## 4. 训练（复现协议）

与全部实验一致：AdamW lr=1e-4 wd=5e-2，cosine T_max=300，bs=32，224²，AMP；
增广 = 256² resize + 水平/垂直翻转 + ±15° 旋转 + 随机裁剪；val Macro-F1 选点，
早停 30；预训练经 `_inflate_fgs` 膨胀变换 + 白名单审计严格加载（unexpected=0）。

```bash
# 最终网络(GEM = MSP+DCH+FGS)
python train_cle_fair.py --model convnext_v6f --num_classes 3 --img_size 224 --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train --data-path-val ./datasets/cle_ac_v1/val \
  --weights /home/login/data/cle/sunfuxiang/classifyML/pth/convnext_tiny_1k_224_ema.pth \
  --save-dir ./weights_v6f_seed42 --epochs 300

# 消融档: convnext_v2m(仅MSP, 包内) / convnext_v2c(MSP+DCH, 在源仓库 convnext_cle_v2.py)
```

## 5. 评测（全指标 + bootstrap CI）

```bash
python evaluate.py --model convnext_v6f \
  --weights ./weights_v6f_seed42/convnext_v6f/model_best.pth \
  --data-path ./datasets/cle_ac_v1/test --bootstrap
```

## 6. 可用模型名（本包）

`convnext_v6f`（最终）/ `convnext_v2m`（MSP-only 消融档）/ 以及
convnext_cle_v5.py 中的其余研究变体（v5se/grn/telu/xrm2/pf/sd、v6c/c2/f/f2/fx/x3、
v6cf 等，均为过程记录，非正式网络）。`convnext_v2c`（+MSP+DCH 档）在源仓库
`models/optimize/convnext_cle_v2.py`，未随包复制，消融数据已包含在 experiment_data。

results.json）重新生成本包全部 CSV；`run_meta/` 含最终网络 3 seeds 的完整训练
