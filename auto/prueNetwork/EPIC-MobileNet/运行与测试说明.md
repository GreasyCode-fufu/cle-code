# 运行与测试说明 — EPIC-MobileNet

环境：`conda activate sunfuxiang`（torch ≥ 2.0、torchvision、scikit-learn、Pillow、numpy、scipy、tqdm、thop）；单卡 GPU。
预训练权重：torchvision `mobilenet_v3_large-8738ca79.pth`（IMAGENET1K_V1），下文记为 `$PTH`。

## 0. 自检（不需要数据集）
```bash
python demo.py          # 构建 + 合成样图前向 + FOV 掩码检查
python selftest.py      # 冻结语义 / 凸头导出等价 / FOV 掩码 / 全部模块导入
```

## 1. 数据格式
`datasets/<name>/{train,val,test}/<类名>/*.jpg`，类别顺序 = 子目录名排序（CLE：Benign_lesions / Malignant_lesions / body_of_stomach_normal）。
非 CLE 数据集评测时须给 `--class-names`（evaluate.py 以其长度确定类别数）。

## 2. 阶段 1：主干训练（原协议：AdamW lr=1e-4 wd=5e-2、cosine T_max=300、bs=32、224²、AMP、val Macro-F1 选点、早停 30）
```bash
# (a) 全量微调 baseline —— 门控需要它的 val 结果; 门控决定不启用 ① 时它也是阶段 1 主干
python train_cle_fair.py --model mobilenet_v3_large --num_classes 3 --img_size 224 --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train --data-path-val ./datasets/cle_ac_v1/val \
  --weights $PTH --save-dir ./weights/mobilenet_v3_large_seed42 --epochs 300 --early-stop 30
# (b) ① 证据保持冻结(/2–/16 参数 + BN 推理态), 原 MLP 头; 与 (a) 同 seed 初始逐位一致, 仅差冻结
python train_cle_fair.py --model mbv3_r6_fz16 --num_classes 3 --img_size 224 --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train --data-path-val ./datasets/cle_ac_v1/val \
  --weights $PTH --save-dir ./weights/mbv3_r6_fz16_seed42 --epochs 300 --early-stop 30
# 阶段 1 的 val 评测(门控用)
python evaluate.py --model mobilenet_v3_large --weights weights/mobilenet_v3_large_seed42/mobilenet_v3_large/model_best.pth \
  --data-path ./datasets/cle_ac_v1/val
```
严格加载审计：`train_cle_fair.py` 仅允许 `classifier.*` 缺失、unexpected 必须为 0，审计写入各 run 的 `run_meta.json`。

## 3. 可迁移性门控（新数据集上是否启用 ①）
```bash
python epic_gate.py --data datasets/cle_ac_v1 --pretrained $PTH \
  --ft-runs weights/mobilenet_v3_large_seed4{2,3,4}/mobilenet_v3_large
# 输出 LP_val / FT_val / gap / decision。三档(gap = FT_val − LP_val):
#   gap ≤ 0       → 全保留: 不做阶段 1, 第 4 步用 --src-model imnet --src-ckpt $PTH --dst-model mbv3_lp_dce4m
#   0 < gap ≤ 1.5 → ① 冻结: 阶段 1 用 mbv3_r6_fz16 → mbv3_fz16_dce4m
#   gap > 1.5     → 全量微调: 阶段 1 用 mobilenet_v3_large → mbv3_dce4m
```
各域实测：CLE 0.61（①）、covid 0.97（①）、BUSI 2.19 / heelBone 2.65 / TCGA 1.71（全量微调）、CUB −6.11（全保留）。

## 4. 阶段 2：解耦凸证据头重拟合（② + ③）
```bash
# 启用 ①: 阶段 1 = mbv3_r6_fz16 → 最终网络 mbv3_fz16_dce4m
python epic_refit.py --src-model mbv3_r6_fz16 --dst-model mbv3_fz16_dce4m --seeds 42 43 44 \
  --src-root weights --dst-root weights --data datasets/cle_ac_v1 --eval
# 全量微调档: 阶段 1 = mobilenet_v3_large → mbv3_dce4m
python epic_refit.py --src-model mobilenet_v3_large --dst-model mbv3_dce4m --seeds 42 43 44 --eval
# 全保留档: 无阶段 1, 直接在 ImageNet 主干上拟合(确定性, 各 seed 结果相同)
python epic_refit.py --src-model imnet --src-ckpt $PTH --dst-model mbv3_lp_dce4m --seeds 42 --eval
```
- 只用 train（拟合）与 val（选 C，网格 3e-4…1，并列取更强正则），不读取 test；预处理与 evaluate.py 完全一致。
- 输出 `weights/<dst>_seed<s>/<dst>/model_best.pth` 与 `run_meta.json`（含源 checkpoint sha256、C 网格与选择、样本数）。
- `--eval` 会接着调用 evaluate.py 评 val/test，并把结果行追加到 `results_epic.csv`；非 CLE 数据集需先 `export RUN_CLASSES="类1 类2 ..."`。

## 5. 评测（9 指标 + 逐类 + bootstrap CI + thop 复杂度 + FPS）

  --weights weights/mbv3_fz16_dce4m_seed42/mbv3_fz16_dce4m/model_best.pth --data-path ./datasets/cle_ac_v1/test

## 7. 注意事项
- 阶段 1 冻结段的 BN 必须保持推理态（`MBV3R6.train()` 已处理）；"冻结卷积 + BN 自适应"在 CLE 上 −1.49（见 negative_screening_summary.csv）。
- FOV 掩码按 ImageNet 均值/方差反归一化后取灰度阈值 0.03；训练/评测须使用 ImageNet 归一化（本仓库 mbv3 默认即是）。
- 训练机器若与本机不同，CUDA/cuDNN 版本差异可能导致数值不逐位一致，但统计结论应保持。
