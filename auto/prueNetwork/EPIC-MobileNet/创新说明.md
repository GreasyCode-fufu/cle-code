# 创新说明 — EPIC-MobileNet（暂定名）

**EPIC = Evidence-Preserving, FOV-Integrated, Convex-head**：面向共聚焦激光显微内镜（CLE）胃黏膜图像三分类
（良性病变 / 恶性病变 / 正常胃体）的轻量网络。基座 MobileNetV3-Large（torchvision IMAGENET1K_V1，top-1 74.04%）。

三个创新点均由数据分析直接导出（`R6_DESIGN.md §1`、`R6_REPORT.md §4`），每一步都在主域 5 个 seed 上逐 seed 配对验证。

---

## 0. 设计出发点：先找到瓶颈，再做设计

对基座做了逐尺度线性探针、误差结构与决策面分析（`experiments/r6_p0_analysis.py`、`r6_p0d_refit.py`），得到三条决定性证据：

| # | 发现 | 数据 | 对应创新 |
|---|---|---|---|
| E1 | **CE 全量微调扭曲了最有判别力的中层证据** | ImageNet 预训练 /16 特征的良/恶性 AUC **0.997**（全部探针最高）；全量微调后降至 0.988，网络输出仅 0.984 | ① |
| E2 | **冷启动分类头是最大瓶颈** | 同一组微调特征上，强 L2 凸分类头比网络自身 1.23M 参数的冷启动 MLP 头 **+1.3 Macro-F1 / +4.0 恶性敏感度**（3/3 seed）；AUC 持平 → 是决策面而非特征的问题 | ② |
| E3 | **评测噪声来自 val 选点下决策面漂移** | 各 run 良/恶性排序 AUC 稳定在 0.975–0.993，但塌陷 run 的最优阈值偏移 −1.5~−6.1，恶性敏感度降到 75–84%（异型增生/癌 → 良性） | ② |
| E4 | **圆形视野外 25–31% 近黑背景稀释证据** | 视野掩码平均池化只在通用（冻结）特征上有益（f12 +1.2 F1） | ③ |

---

## 创新 ① 证据保持微调（Evidence-Preserving fine-tuning）

**做法**：阶段 1 冻结 `features[0..12]`（/2–/16，卷积参数 + BN 推理态 = ImageNet 统计量），只微调 /32 段与分类头；
训练协议（AdamW lr=1e-4 wd=5e-2、cosine、bs=32、增广、val Macro-F1 选点、早停 30）完全不变。

**动机**：E1 —— /16 处的通用结构证据已能近乎完美地区分良/恶性，小样本（2,077 张）全量微调反而把它"学坏"（拟合训练患者特异性）。

**性质**：
- 可训练参数 4.21M → 3.41M；/2–/16 部署时与 ImageNet 模型**逐位共享**（多任务部署可共用前段）。
- 冻结段 BN 保持 ImageNet 统计量是关键：对照实验中"冻结卷积 + BN 自适应"（TinyTL 式）在 CLE 上 −1.49，说明保住的是"卷积核 + 归一化"的完整证据通路。
- 冻结段无权重梯度 → 训练更快、显存更省（阶段 1 单 run 约 3.5 min，基线 5–7 min）。

**相关工作与区别**：LP-FT（Kumar et al., ICLR 2022）指出微调会扭曲预训练特征；Surgical fine-tuning（Lee et al., ICLR 2023）按分布偏移类型选择微调层。
本工作以**逐尺度探针定位"证据所在尺度"（/16）**来确定冻结深度，并配合 ② 的解耦分类头；同时给出**可迁移性门控**（§4）决定 ① 是否启用。

**消融**：baseline 94.16 → +① **95.62（+1.46，5/5 seeds）**，κ +2.20，AUROC +0.41。

## 创新 ② 解耦凸证据头（Decoupled Convex Evidence head, DCE）

**做法**：阶段 2（`epic_refit.py`）冻结阶段 1 选出的主干，在证据向量上以**强 L2 多项逻辑回归**拟合分类头；
正则强度 C 在网格 {3e-4…1} 上**仅按 val Macro-F1 选择**（并列取更强正则），全程不读取 test；拟合结果（含标准化 μ/σ）写回 `Linear`，部署时就是一个线性层。

**动机**：E2/E3 —— 端到端训练的冷启动宽 MLP 头在近可分的训练集上过拟合，而 val 选点又在未退火的噪声轨迹上"抽签"，导致恶性决策面漂移。
凸问题有唯一解、对初始化与 seed 不敏感，把"选一个噪声峰上的 checkpoint 头"变成"在固定证据上解一个凸问题"。

**性质**：
- 分类头参数 1.23M → 3.4K（1136×3）；整网 4.21M → **2.975M（−29.3%）**。
- 跨 seed 标准差 1.07 → **0.30**（①→①+②），恶性敏感度 93.2 → **96.3**。
- 失败的替代方案（如实记录）：端到端线性头 −1.03（强 L2 + 固定特征才是关键）；事后 logit adjustment 不能修复塌陷。

**相关工作与区别**：解耦表征与分类器（Kang et al., ICLR 2020）用于长尾识别；本工作将其用于**小样本医学分类中冷启动头的决策面稳定化**，并以 val 选择正则强度、与多尺度 FOV 证据结合。

**消融**：+①+② **96.05（+1.90）**，κ +2.84，恶性敏感度 +6.25。

## 创新 ③ FOV 感知多尺度证据（FOV-aware multi-scale evidence）

**做法**：从 /4（f3, 24ch）、/8（f6, 40ch）、/16（f12, 112ch）、/32（f16, 960ch）四个抽头取证据，
**只在圆形视野内的组织区做掩码平均池化**，拼接为 1136 维证据向量送入 ②。

视野掩码（`fov_weights`）：输入反归一化灰度 → 4× 平均下采样到 1/4 分辨率 → 3×3 平滑（约等于原分辨率 12px，填平腺腔等小暗区）
→ 阈值 0.03 → 各尺度自适应平均后归一化为池化权重。无暗背景的图像自动退化为普通 GAP。

**动机**：E4 —— CLE 方形画幅内嵌圆形视野，视野外近黑背景占 25–31%，普通 GAP 让这部分无信息区域参与平均；
多尺度抽头让分类器直接看到中低层的结构证据（E1：/16 证据最强），而不只依赖 /32。

**性质**：
- 零参数；在 1/4 分辨率上计算，CPU 单线程延迟 **+1.4%**（全分辨率 15×15 掩码曾使 CPU +43%，已改）。
- 掩码只对冻结的通用特征有益（与 E4 一致），因此与 ① 协同：① 保住通用特征，③ 在其上去除背景稀释。

**消融**：+①+②+③ **96.51（+2.35）**；相对 ①+②：多尺度 +0.18，FOV 掩码 +0.28（4/5 seeds ↑，1 持平）。

## 1. 主域结果（cle_ac_v1 test，576 张，5 seeds 42–46，同批同协议）

| 配置 | Macro-F1 | κ | MCC | BalAcc | AUROC | 恶性敏感度 |
|---|---|---|---|---|---|---|
| baseline MobileNetV3-L | 94.16±0.56 | 91.22 | 91.29 | 94.02 | 99.10 | 90.00 |
| +① | 95.62 | 93.42 | 93.45 | 95.54 | 99.51 | 93.18 |
| +①+② | 96.05 | 94.05 | 94.06 | 96.09 | 99.49 | 96.25 |
| **+①+②+③（EPIC-MobileNet）** | **96.51±0.40** | **94.73** | **94.73** | **96.54** | **99.57** | **96.70** |

- 官方 3 seeds（42/43/44）：96.43 vs 94.08 = **+2.35**。
- 显著性：5/5 seeds 的 ΔF1 配对 bootstrap 95% CI 全部 > 0；McNemar 逐 seed p < 0.05；跨 seed 配对 t = 20.4，p = 3.4×10⁻⁵。
- 误差结构（5 seeds 合计）：错误 168 → 101（−40%）；**漏诊恶性（癌/异型增生 → 良性）63 → 18（−71%）**；
  代价是萎缩被过判为恶性 32 → 39（临床上"宁可多查不漏诊"的方向）。
- 对比轻量主干（5 seeds）：StarNet-S2 93.47、GhostNet 93.08、FasterNet-T0 93.06、ShuffleNetV2 92.49、MobileNetV4-Conv-S 89.71。

## 3. 可迁移性门控（决定 ① 的保留深度；只用 train/val）

`gap = FT_val − LP_val`（全量微调 baseline 的 val Macro-F1 − 冻结 ImageNet 四尺度线性探针的 val Macro-F1，`epic_gate.py`）：

| gap | 含义 | 阶段 1 | 部署结构 |
|---|---|---|---|
| ≤ 0 | 冻结特征已不劣于全量微调 → 微调只会失真 | 不训练（全保留） | ImageNet 主干 + ②③ |
| (0, 1.5] | 冻结特征接近微调 → 只适配顶层 | ① 冻结 /2–/16 | `mbv3_fz16_dce4m` |
| > 1.5 | 低/中层统计需要适配（超声、X 光） | 全量微调 | `mbv3_dce4m` |

理论依据：LP-FT（Kumar et al., ICLR 2022）—— 线性探针接近全量微调时，微调主要带来特征失真。
阈值（0、1.5）在 CLE/BUSI/heelBone/covid/CUB 上拟定：门控在这 5 域都选中了三档中的最优档（covid 与最优差 0.08）。
**TCGA 为预注册的样本外检验**（`experiment_data/R6_GATE_PREREG.md`，预测在查看任何 TCGA test 结果之前提交到 git）：
gap +1.71 → 预测"全量微调 + ②③"最优 —— **结果成立**：三档 81.21 / 83.84 / **84.20**，所选档领先次优 0.36，比 baseline +1.45。
汇总：门控在 6/6 域选中三档最优档（covid 与最优差 0.08）。

## 4. 负结果（如实归档，见 `experiment_data/negative_screening_summary.csv`）
初版方案的三个创新点借自模块库（StarNet 星运算头、LSNet 的 LSConv、InceptionNeXt 的 IDC、MatchED 边缘先验）以及 /16 预训练锚定，
在 5-seed（或 2-seed 配对）检验下全部未通过；其中星乘头 3-seed +0.31 在补到 5 seeds 后为 −0.04 —— 本数据集单 run 标准差 0.6–1.7，
3 个 seed 无法分辨 ±0.5 的效应，这是本轮把关键决策全部改用 5 seeds 的原因。

## 5. 局限
- ① 的收益依赖目标域与 ImageNet 的可迁移性，需按 §3 的门控决定保留深度；门控阈值在 5 个域上拟定，仅 TCGA 一个样本外检验，更多域上的可靠性有待验证。
- GPU batch=1 延迟 +18%（掩码引入约 20 个小 kernel，启动开销受限场景），bs64 吞吐 −8%；CPU 单线程 +1.8%、4 线程 +3.7%。
- 训练分两阶段（阶段 2 为秒级到分钟级的凸拟合）。
