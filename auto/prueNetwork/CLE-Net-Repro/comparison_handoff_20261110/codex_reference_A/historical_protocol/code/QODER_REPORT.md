## 3. 遇到的问题与处置

1. **SSH 端口转发占用**：`LocalForward 1455` / `RemoteForward 12789` 每次连接报占用警告，不影响远程命令执行，未处理。
2. **串行→并发 2 调整**：任务书默认 conc=1；用户指示可多并发以高效利用资源。实测单任务 GPU util 94%、显存 5.5/48GB、24 核 CPU 负载低（数据加载 num_workers=3、OMP/MKL=2）。故停掉串行 runner → 清理进行中 `convnext_egb_seed43` 残留目录（rm -rf）→ 重建剩余 15 项作业表 → 以 conc=2 重启。结果 GPU util 99%、CPU 负载 ~4.5/24，无数据加载抢占；GPU 已饱和故不再提至 3。egb_s43 因中断重跑一次（重跑前已清残留）。
3. **无失败 run**：16/16 全部 ok，未触发"失败重跑清残留"流程；历史行未改动。
