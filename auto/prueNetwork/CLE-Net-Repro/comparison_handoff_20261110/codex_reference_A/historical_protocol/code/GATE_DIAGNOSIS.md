## 二、P0 发现：三个创新模块的门控在训练后仍未打开

### 2.1 训练后门控标量实测（全部 30 个 ckpt）

| 模块 | 门控 | 典型 \|g\| | 最大 \|g\| |
|---|---|---|---|
| EGB | `egb_g`（逐块标量，共 15 个） | 1e-3 量级 | 0.00426 |
| ESA | `esa_g`（12 个） | 1e-3 量级 | 0.00424 |
| SCG | `scg_g`（12 个） | **1e-5 ~ 1e-4** | 0.00119 |
| HSC | `hsc.g`（1 个） | 1e-4 量级 | 0.00074 |

分支输出典型幅度 O(1)，`g·φ(x)` 的贡献 ≤ 0.4%，数值上可忽略。

### 2.2 决定性干预实验（test 集 576 张，seed 42）

把门控**强制置 0**（模块完全关闭）后重测 macro-F1：

| 模型 | orig（训练所得 g） | **off（g=0）** | ×100 | one（g=1.0） |
|---|---|---|---|---|
| convnext_egb | 0.9619 | **0.9619** | 0.9671 ↑ | 0.9568 |
| convnext_scg | 0.9617 | **0.9617** | 0.9617 | 0.9532 ↓ |
| convnext_hsc | 0.9511 | **0.9511** | 0.9511 | 0.9476 ↓ |
| convnext_esa | 0.9537 | **0.9537** | 0.9537 | 0.9537 |
| CLE-Net (A+B+C) | 0.9581 | **0.9581** | 0.9581 | 0.9460 ↓ |

**orig 与 off 逐位完全相同（4 位小数）——三个模块的功能贡献精确为零。**

### 2.3 由此推出的结论

1. **CLE-Net / S-Net 及各消融变体在功能上 ≡ ConvNeXt-T baseline**。论文消融表中 0.9476 → 0.9553 的差异来自随机种子与初始化随机流，不是模块设计。
2. **SCG / HSC 存在「零门控死锁」**：分支含可训练参数，但梯度链为 `∂L/∂W = g · (...)`，`g≈0` 使分支收不到梯度、停留在随机初始化；其输出是无意义噪声 → `∂L/∂g = ⟨∂L/∂y, φ(x)⟩` 期望为 0、batch 间正负抵消 → g 在 0 附近随机游走 → 永不打开。`g=1.0` 时 F1 掉 0.85pp（SCG）/ 1.21pp（CLE-Net），证实分支输出有害。
3. **EGB 是例外，且是真正有希望的一条**：`_PFECore` 为确定性零参数算子，不存在死锁；`g×100` 时 F1 由 0.9619 → **0.9671（+0.52pp）**。说明频域边缘-结构先验**确实携带任务有效信息**，只是门控被严重欠训练。
4. **HSC 的 8×8 注意力是伪实现**：`q,k,v` 各为 `(B,8,96)`，`q@kᵀ` 得 `(B,8,8)` 的**头间**注意力，既非 768 通道间的通道注意力，也非标准多头自注意力（缺序列维）。表达能力极弱，与其设计意图不符。

## 三、根因（可写进论文的 honest account）

- 优化器为**单一参数组**：`optim.AdamW(pg, lr=1e-4, weight_decay=5e-2)`，无 `no_decay` 豁免 → 门控标量被 wd 持续拉向 0。
- `lr=1e-4` 且 ConvNeXt `layer_scale_init_value=1e-6`，残差分支梯度本就极小；标量门在 300 epoch 内净累积仅 ~1e-4（≈ 单步 Adam 更新量），说明梯度方向几乎完全随机、正负抵消。
- 零初始化门控的**死锁**未被识别：zero-init 只适合「分支本身已可用」（确定性算子或预训练分支），不适合「分支需要从头学」。

---

## 四、修复方案（按优先级）

| 优先级 | 措施 | 预期效果 |
|---|---|---|
| P0 | 门控参数加入 `no_decay` 组，并单独设 10×–100× 学习率 | 解除 wd 压制，让 g 真正成长 |
| P0 | 破解死锁：改为**仅新分支最后一层零初始化**（ControlNet / LoRA 标准做法），分支内部正常参与训练 | SCG/HSC 分支可学到有用表示 |
| P0 | HSC 重做：改为真正的通道注意力（SE 式通道门控，或 768 token 间注意力），弃用 8×8 头间矩阵 | 与论文描述对齐，恢复表达能力 |
| P1 | EGB 门控由标量升级为**通道级向量**，或直接以 `g×100` 量级初始化做研究 | EGB 已验证 `g×100` +0.52pp，潜力最大 |
| P1 | 补统计检验：576 张测试集上 bootstrap 95% CI + 配对比较 | 0.77pp 差异在 576 样本下需显著性背书 |
