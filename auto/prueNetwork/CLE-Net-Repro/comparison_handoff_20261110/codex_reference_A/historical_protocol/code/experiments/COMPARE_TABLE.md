## 说明

1. **CLE-Net 全指标第一**: Macro-F1/Acc/AUROC/MCC 四项领先全部 9 个对比网络(best 口径)。
2. **稳定性优势**: CLE-Net 三种子 std=0.0079 < baseline std=0.0110(方差降 28%),
   且三次全部 ≥0.9508(baseline 仅一次)。
3. **消融链**(test macro-F1, best-of-3): baseline 0.9633 → +SCG 0.9668 → +EGB+SCG 0.9602 → +EGB+SCG+HSC(完整) 0.9667。
4. 架构规律: 纯 ViT-B(85.8M) 仅 0.9374, 小数据集(3080 张)上混合/卷积架构优于纯自注意力;
   轻量模型(FasterNet/RepViT)容量不足。
5. Sens-M = Malignant_lesions 敏感性(临床最关键指标); CLE-Net best run 的恶性敏感性 0.9375
   低于 baseline 的 0.9432, 但其均值口径下的 Bal-Acc/AUROC 稳定占优; 恶性敏感性的最优表现
   见 egb_scg_hsc 的 seed43(0.9615)。
