# 最终网络报告 — FD-ConvNeXt (convnext_fgc_dsd), 2026-11-02 凌晨定型

## 1. 网络结构(三创新点)

**FD-ConvNeXt = ConvNeXt-T + DSD(stage2) + FGC(stage4)**, 模型名 `convnext_fgc_dsd`。
实现: models/optimize/convnext_ep.py; 预训练投影初始化: train_cle_fair.py transforms。

- **创新点1 FGC (Frequency-domain Global Convolution, stage4)**:
  每块 7×7 dwconv(7×7 特征) 整体替换为 rfft2 可学习频域滤波(x * H(u,v) 对偶)。
  感受野从 7×7 扩展到全图; 初始化 = roll(预训练核,-3) 的 rfft2(循环卷积频域对偶投影)。
  动机(数据驱动): M→B 漏诊样本高频占比低 15%, B/M 高频总量重叠(0.0112 vs 0.0103)
  → 需要可学习的全局频率重组而非固定核。参数 37.7K→86K/块。
- **创新点2 DSD (Directional Strip DWconv, stage2)**:
  每块 7×7 dwconv 替换为 (7×1)+(1×7) 并联条带深度卷积 + 通道级 softmax 混合。
  参数 49C→14C(-71%); 初始化 = 预训练核行和/列和投影(幅值守恒)。
  动机: 胃体腺体方向性管状结构, H/V 条带显式编码方向感受野; speckle 噪声下
  参数减载提升小样本稳健性。
- **创新点3 算子-位置分配原则 (BM 矩阵消融支撑)**:
  "频域算子宜深层(语义级频率重组), 方向算子宜浅层(纹理级方向性)":
  | 配置 | 2s均值 |
  |---|---|
  | **FGC@4+DSD@2 (最终)** | **95.54**(5s 95.58) |
  | FGC@3+DSD@2 | 93.80 |
  | FGC@4+DSD@1 | 95.08 |
  | FGC@3+DSD@1 | 92.90 |
  | FGC@3+4+DSD@2 | 92.31 |

  FGC 组件级跨域三域显著正(CLE+1.17/Covid+0.64/CUB+1.08) — 通用频域证据重组;

  heelBone/busi 为 X光/超声域, 成像物理与共聚焦荧光差异大, 诚实报告为域边界。

## 4. 探索矩阵(负结果记录, 27+ 变体)

主域深度饱和(94.8-96.4 抖动, ±0.5pt≈3张), 以下全部回退或无显著增益:
- head 级: DPH(GAP+GMP 拼接头) 5s=95.78(+1.02, 高方差, 用户弃) / CMP(通道级混合池化) 2s=95.37 / AEP(softmax 谱池化) 94.69 / DPH-lite 94.99
- block 级乘性重标定: FESR 两代(软启动) 最高 95.59 但与一切组合冲突
- 组合: dph+X 全回退 / cmp+X 弱 / dpea(dpea2) 95.08 / fgc_dsd_fse 94.16
- 损失/自监督: AMH(角度间隔, 两代) / MFM(掩码重建, 两代) / 类权重 全部 94.9-95.4
- 投影初始化消融(ri 对照): 组合版 +0.11 / FGC 单独版 ±0.3 → 不显著, 作技术贡献不作创新点
- 位置矩阵: 见创新点3表(FGC 仅宜 stage4)
