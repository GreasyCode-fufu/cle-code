## 方法

**D4 推理期对称化**（方法出处：`/home/login/data/cle/auto/Network/demo/CLE-Net-Repro/resnet34_gnn/`
，2026-11-15）：CLE 共聚焦视野各向同性（无规范方向），推理时对输入取
D4 二面体群 8 视图（4×90°旋转 × 翻转）logits 平均。零参数、训练不变。

## 实验设计（配对因果比较）

- **同一 checkpoint** 上做 单视图 vs D4 对称化 双模评估 —— 差值纯粹来自对称化，
  无训练噪声、无随机性（方法学出处同上，"全 RNG 对齐配对测量"）。
- **复用各项目自己的 `evaluate.py`**（load_model / build_transform / run_inference /
  compute_metrics）——模型构建、权重加载、预处理（短边 Resize 256 + CenterCrop 224 +
  ImageNet 归一化）、九项指标口径全部与各项目官方评估一致；
  GEM-ConvNeXt 单视结果与其 `cle_main_results.csv` **逐位一致**（0.9599/0.9653/0.9636）
  作为管线正确性验证。
- **不修改任何原始项目文件**；全部产物在 `demo/`。checkpoint 为各项目已有的
  CLE 主域（cle_ac_v1, test 576）训练产物，位置见 `eval_d4.py` PROJECTS 表。

## 观察与解释

1. **涨点普遍存在**：6/6 网络 9/9 指标均值上涨；AUROC 在全部网络全部 seed 上涨
   （阈值无关指标的稳定改善 = 排序质量提升，符合方差缩减机理）。
2. **幅度与"网络自身已对称化的程度"负相关**：
   - EPIC-MobileNet（MobileNetV3 基座）+0.0094 最大——轻量骨干保留的视角方差最多；
   - GEM-ConvNeXt +0.0004 最小——其 FGS 茎干（Sobel 第4通道）与多尺度稠密头
     已隐式编码部分方向鲁棒性；DSG-Net 的方向结构校准（OCA）同理（+0.0036，
   且 seed44 微负）。
   - 即：结构创新越"吃掉"方向方差，D4 的边际收益越小——与
     resnet34_gnn 中 flip4 重训打平的"增益吸收"现象一致。
3. **Kappa/MCC 涨幅约为 macro-F1 的 1.5 倍**（EPIC +0.0141），不对称错误减少更多。
4. 代价：推理 8× 前向（训练开销为零变化）。
5. 备注：DPFusion 的单视均值 0.9453 来自 `weights_cleac3nets_v1` 三种子 checkpoint
   及其自身评估器；其 README 的 0.9740 为另一单点口径，两者不冲突但不可混用。

各项目创新网络**相对 baseline 有涨点**的泛化域（按各项目自报数据选定），在同一
checkpoint 上做 单视图 / +D4(翻转×90°旋转, 8视图) / +flip4(纯翻转群 V4, 4视图)
三模配对评估。单视结果与各项目发表数字逐位一致（GEM@cub 0.8053、GEM@tcga 0.8571、
EPIC@covid 0.9868、EF@busi 0.8692 等），管线可信。跨域训练与主域同协议
（H/V flip p=0.5 + ±15° 旋转增强——翻转不变性在**所有域**都被显式声明）。

## 结论：对称化群的收益边界 = 增强声明的不变性 ∪ 模态真实几何

1. **D4 仅在各向同性模态（显微）涨点**：TCGA 病理显微 3/3 组合全 seed 正
   （+0.0044~+0.0086）——与 CLE 主域结论一致；其余模态（CT/超声/X光/自然图像）
   12/13 组合为负，EPIC@covid 最重（-0.0381，MobileNetV3 不变性弱 + CT 有规范方向，
   90° 旋转产生强 OOD 输入）。
2. **flip4（纯翻转群）几乎处处安全且正向**：15/16 组合 Δ≥0（另 1 个 -0.00004 级
   零平），实质涨幅 +0.0013~+0.0076——因为 H/V 翻转不变性由训练增强在所有域
   显式声明，翻转平均只会消除已声明的视角方差。
3. **实用选择准则（可直接入论文）**：
   - 各向同性模态（显微/病理）：用 D4（兑现在场几何的全部先验，D4>flip4>single）；
   - 各向异性模态（超声/CT/X光/自然图像）：只用 flip4（= 增强声明的不变性；
     加入未声明的 90° 旋转不变性会伤害）。

复现：`for c in <项目@域>; do python demo/eval_d4.py --project "$c" --modes single,d4,flip4; done`
（组合清单见 eval_d4.py XD_PROJECTS；每组合需独立进程，避免 models 包跨项目缓存）
