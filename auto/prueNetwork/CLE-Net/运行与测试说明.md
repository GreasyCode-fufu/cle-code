## 3. 快速自测（无需任何权重，CPU 即可）

```bash
python -c "
import torch
from cle_fair_common import build_model
m = build_model('convnext_egb_scg_hsc', num_classes=3).eval()
y = m(torch.randn(1, 3, 224, 224))
print('输出:', tuple(y.shape), '参数量:', sum(p.numel() for p in m.parameters())/1e6, 'M')
"
# 期望：输出: (1, 3)，参数量 ≈ 31.60M
```

## 4. 训练（公平协议：300 epochs / 早停 30 / val Macro-F1 选点 / AMP）

```bash
python train_cle_fair.py --model convnext_egb_scg_hsc --num_classes 3 --img_size 224 \
  --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train \
  --data-path-val   ./datasets/cle_ac_v1/val \
  --weights /home/login/data/cle/sunfuxiang/classifyML/pth/convnext_tiny_1k_224_ema.pth \
  --save-dir ./weights/cle_net_seed42 --epochs 300
```

启动后注意权重审计行，应为：

```
[weights] strict load passed | classifier_missing=3 ... unexpected=0
```

`unexpected=0` 表示 ImageNet 预训练张量无一被丢弃（新分支按白名单
`egb_g / scg / scg_g / hsc` 允许缺失，初始零门控 ⇒ 起步与基线逐位等价）。

## 5. 评测（全指标：macro/weighted F1、balanced acc、AUROC、AUC-PR、Kappa、MCC、逐类 sens/spec/prec）

```bash
python evaluate.py --model convnext_egb_scg_hsc \
  --weights ./weights/cle_net_seed42/<run目录>/model_best.pth \
  --data-path ./datasets/cle_ac_v1/test
```

## 6. 可用的其他模型名（同注册表）
