## 3. 测试（无需任何权重即可跑前向；自带自检含恒等断言）

### 3.1 自带冒烟自检（推荐）

```bash
python smoke_test.py
```

断言项：构建 `build_model(3)` → 前向 [1,3] → 参数量 27,861,027（+38,592）→
加载 ImageNet ema 预训练严格审计（0 unexpected）→ **与 baseline
ConvNeXt-T 随机权重下逐位恒等**（零初始化验证）。本包复制后已实测全部通过。
（若预训练文件路径不可达，仅恒等性之外的加载断言会提示，其余照常。）

### 3.2 代码调用

```python
import torch
from model import build_model

model = build_model(num_classes=3)      # CUB 等 200 类传 num_classes=200
logits = model(torch.randn(1, 3, 224, 224))   # [1, 3]，未经 softmax
```

输入为 224×224、ImageNet 归一化 mean=[0.485,0.456,0.406] std=[0.229,0.224,0.225]。
训练侧增广与评测预处理与原协议一致（训练 Resize(256,256)+翻转/旋转15°+RandomCrop224；
评测 Resize(256)→CenterCrop(224)）。

### 3.3 最小前向自测（不依赖预训练权重）

```bash
python -c "
```

## 4. 训练（单阶段，与 baseline 完全同协议）

AdamW lr 1e-4 / wd 5e-2、bs 32、≤300 epoch、Cosine(T_max=300)、AMP、早停 30、
val macro-F1 选点、seeds 42/43/44：

```bash
python train_cle_fair.py --model convnext_tiny_cle_oca_strip --num_classes 3 --img_size 224 \
  --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train \
  --data-path-val   ./datasets/cle_ac_v1/val \
  --weights /home/login/data/cle/sunfuxiang/classifyML/pth/convnext_tiny_1k_224_ema.pth \
  --save-dir ./weights_dsg_seed42 --epochs 300
```

严格加载允许缺失 `head.*` 与新分支段（`dose/oca1/oca2`），0 unexpected；
初始函数与 baseline 逐位一致，训练中渐进解锁。

## 5. 评测（全指标口径）

```bash
python evaluate.py --model convnext_tiny_cle_oca_strip \
  --weights ./weights_dsg_seed42/<run目录>/model_best.pth \
  --data-path ./datasets/cle_ac_v1/test
```
