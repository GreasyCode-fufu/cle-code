# DSG-Net 创新说明

**正式网络**：`convnext_tiny_cle_oca_strip`（2026-10-30 由同名代码注册名更名为 DSG-Net）
**基座**：ConvNeXt-Tiny（ImageNet-1k ema 预训练，27,822,435 参数）
**任务**：CLE 图像三分类（Benign / Malignant / Normal），并验证跨域泛化
**核心代码**：`models/optimize/convnext_cle_dsg.py`（本文档为精要；
完整机制/数学/文献见 `docs/ARCHITECTURE.md`）

## 一句话概括

针对 CLE 图像的**方向结构校准**网络：在 ConvNeXt-Tiny 上以 A→B 顺序叠加两个
**零初始化、逐位恒等起步**的方向统计模块（OCA 方向相干性门控 + DOSE-Strip
方向门控条带上下文），仅新增 **38,592 参数（+0.14%）**，单独使用均不稳定、
**组合产生协同**。

## 设计约束

零初始化门控 ⇒ 载入预训练后初始函数与 baseline **逐位恒等**（`smoke_test.py`
含该断言，已通过）；训练中渐进解锁。预训练严格加载允许缺失 `head.*` 与新分支
段（`dose / oca1 / oca2` 白名单），0 unexpected。

## 创新点 A：OCA 方向相干性门控（Orientation-Coherence Attention）

- **灵感来源**：219 DHOGSA（AAAI 2026，"梯度作为条件"）+ 233 SDGW（CVPR 2026，
  局部统计归一化加权）+ PFESA（MICCAI 2026，零参数统计注意力哲学）。
- **机制**：对 stage2/3 特征做 fp32 有限差分，统计 4 方向（|gx|、|gy|、|gx+gy|、
  |gx−gy|）的 3×3 局部平均能量 e_i；逐通道方向集中度
  `dom = max_i(e_i)/Σe_i ∈ [0.25,1]`，逐图像标准化后 sigmoid 得空间组织度图 w；
  零初始化逐通道增益乘性调制 `x ← x + s⊙(x·w)`。
- **数学含义**：w 是方向分布熵倒数的单调变换——方向谱越集中（结构走向越一致）
  权重越高。仅 **+576 参数**，核心零参数。
- **组织学动机**：正常/良性腺体排列规则（方向相干高），恶性结构紊乱（相干低）；
  该图直接编码"组织方向紊乱度"这一判别证据。

## 创新点 B：DOSE-Strip 方向门控条带上下文（Direction-gated Strip Context）

- **灵感来源**：234 DEGConv（CVPR 2026，方向条带边缘门控）+ 138 StripConv
  （AAAI 2026，长条带卷积）+ 16 IDC（CVPR 2024，大核分解）。
- **机制**：仅在 stage3 的 block 2/5/8，对 dwconv 输出计算通道均值级的 4 方向
  能量归一化分布 gate（每图每通道 4 维），加权 1×15 与 15×1 深度条带卷积及
  两个共享权重复合响应（捕获对角结构），逐通道零尺度残差注入
  `y ← y + s⊙Σ_i g_i·b_i(y)`。
- **与既有工作的本质区别**：StripConv 类方法是**无条件**固定条带；本模块的
  **感受野形状由内容方向谱决定**（方向能量高的方向获得更大上下文权重）。

## 叠加协议与迭代证据

A 单独（均值 −0.60pp）与 B 单独（−0.08pp）均不稳定，**A+B 组合产生协同**：
cle_ac 三种子 0.9637 / 0.9741 / 0.9493，s43 单点 0.9741 为项目全部历史运行最高。
方向统计模块两两互斥（oca+gds −0.70pp）；PTG / GDS / CALS / CFD 等第三创新与
针对性损失均验证为不叠加，负结果完整保留于原项目
`experiments/cle_auto/DSG_NET_REPORT.md`（34 个 run 全记录）。

## 验证结论（n=3，seeds 42/43/44，逐种子配对 vs ConvNeXt-T）

| 域 | DSG-Net | baseline | 差值 |
|---|---|---|---|
| **cle_ac（源域）macro-F1** | 0.9624±0.0102 | 0.9558±0.0026 | **+0.65pp**（Kappa/MCC/mSpec/mSens/Acc 等 **7/7 指标均值全正**） |
| **Covid 胸片（跨域）** | 0.9846±0.0015 | 0.9802±0.0010 | **+0.44pp，3/3 种子全正** |
| **CUB 200 类细粒度（跨域）** | 0.7871±0.0028 | 0.7761±0.0056 | **+1.11pp，3/3**（Top-1 +1.28pp） |
| BUSI 超声（跨域） | 0.8555±0.0114 | 0.8678 | −1.24pp（AUROC +0.85pp）——方向先验对超声散斑不适配，如实呈现 |

方向结构先验在细粒度纹理（CUB 羽枝）与大结构方向（CXR 肋骨/膈肌）域上泛化最好。
