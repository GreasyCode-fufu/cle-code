# SF-ConvNeXt 创新说明

**正式网络**：`convnext_v2bc`（主类 `ConvNeXtV2`）
**基座**：ConvNeXt-Tiny（ImageNet-1k 官方 ema 权重，键重映射严格加载）
**任务**：CLE 图像三分类（Benign / Malignant / Normal）
**核心代码**：`models/optimize/convnext_cle_v2.py`（配合 `models/optimize/convnext_cle.py`
的 Haar 小波算子与 `models/Convnext.py` 基座）

## 一句话概括

**尺度–频率感知**的 CLE 分类网络：在 ConvNeXt-T 的 stage-3/4 做**替换式**
频域多尺度深度卷积（WR），并把分类头改为**三尺度证据拼接**（CH）——
两处均为**结构化替换（不可旁路）**，区别于并联门控式即插即用模块。

## 创新点 1：WR — 频域多尺度卷积块（stage-3/4 全部 12 个 block）

**结构**：7×7 深度卷积整体替换为 WTConv（ECCV 2024 忠实移植，内联 Haar/db1、
免 pywt 依赖）：

- **基卷积分支**：7×7 深度卷积，**直接继承 ImageNet 预训练权重**（经
  `train_cle_fair.py` 的 `MODEL_CHECKPOINT_TRANSFORMS["convnext_v2bc"] = _remap_wr`
  把 `dwconv.{weight,bias}` 重映射到 `WTConv.base_conv.*`）——预训练知识零损失；
- **Haar 两级级联小波路径**：每次分解得 LL/LH/HL/HH 四子带，各子带 3×3 分组
  深度卷积后逆变换重构；**尺度初始 0.1**（小步幅起步，避免扰动预训练特征分布）；
- **效果**：感受野随分解级数**指数扩展**、参数仅**线性增加**
  （27.80M → 28.67M / 4.45G → 4.64 GMACs）。

**动机**：CLE 图像中腺体（大尺度低频）与细胞核/边缘纹理（小尺度高频）共存，
固定 7×7 感受野无法同时覆盖；小波域卷积让"一个算子内部"具备多尺度谱分解能力。

## 创新点 2：CH — 三尺度拼接分类头

**结构**：头输入 = [LN₄(GAP(f₄)); LN₃(GAP(P₃f₃)); LN₂(GAP(P₂f₂))] ∈ R^2304
（fᵢ 为 stage-i 特征，P 为 1×1 投影），分类器稠密读取**全部三尺度证据**。

**动机**：恶性判别既需要 stage-4 的高级语义，也需要 stage-2/3 的中尺度腺体
结构证据；仅 GAP(f₄) 会丢弃中尺度信息。

## 消融变体工厂（同文件，registry 全部可用）

`convnext_v2a`（WR 位置消融）/ `v2b`（WR 单独）/ `v2c`（CH 单独）/
`v2ab` / `v2abc`（三创新点链）/ `v2ac` / **`v2bc`（B+C，主干预训练保持最佳，
正式网络）** / `v2bc4`（WR 仅 stage4 的轻扰动组合）；另有 WS（WaveletStem
小波茎干替换）变体组件。

## 主要结果（cle_ac_v1 test，576 张，三分类）

| 指标 | ConvNeXt-T 基线(5seed 均值) | SF-ConvNeXt(3seed 均值) | 最优 run(1000 次 bootstrap 95% CI) |
|---|---|---|---|
| Macro-F1 | 0.9476±0.0084 | **0.9600±0.0065** | **0.9672** [0.9518, 0.9806] |
| Accuracy | 0.9479 | **0.9601** | 0.9670 [0.9514, 0.9809] |
| Cohen's Kappa | 0.9216 | **0.9399 (+1.83)** | 0.9504 |
| MCC | 0.9222 | **0.9401 (+1.79)** | 0.9505 |
| Macro-AUROC | 0.9940 | **0.9964** | 0.9967 [0.9939, 0.9987] |
| Params / MACs | 27.80M / 4.45G | 28.67M / 4.64G | — |

在 **18 个对比主干**（ResNet/ResNeXt/MobileNetV3/ShuffleNetV2/GhostNet/
FasterNet/DeiT-T/S/B/ViT-B/Swin-T/PVT-T/PoolFormer/ConvNeXt-S 等）中
Macro-F1 **排名第 1**：优于 3 倍参数的 DeiT-B（+1.25pt）与 2 倍参数的
ConvNeXt-S（+0.62pt）。逐类（最优 run）：恶性 sens/spec/prec = 0.960/0.985/0.966。

**跨域迁移性结论**：CH 头为通用改进（跨数据集为正），WR 为 CLE 特化
（CIFAR-10 跨域 v2bc≈基线、v2c 略优；通用域收益主要来自 CH）。
