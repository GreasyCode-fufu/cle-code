## 3. 测试

### 3.1 模型构建自测（无需任何权重）

```bash
python -c "
import torch
from cle_fair_common import build_model
m = build_model('convnext_v2bc', num_classes=3).eval()
y = m(torch.randn(1, 3, 224, 224))
print('输出:', tuple(y.shape))
"
# 期望：输出: (1, 3)
```

### 3.2 demo.py（构建 → 加载最优权重 → 前向；权重缺失时自动降级为随机初始化）

```bash
python demo.py            # 默认找 ./weights/sf_convnext_best.pth 或见 --help
python demo.py --cpu      # CPU 推理
```

推理预处理（与训练一致）：

```python
transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
```

类别顺序：`["Benign_lesions", "Malignant_lesions", "body_of_stomach_normal"]`
（见 class_indices.json）。

## 4. 训练（复现协议）

AdamW lr=1e-4 wd=5e-2，余弦退火 T_max=300，bs=32，224²，AMP；增广 =
256² resize + 水平/垂直翻转 + ±15° 旋转 + 随机裁剪；按验证集 Macro-F1 选
checkpoint（早停 30）：

```bash
python train_cle_fair.py --model convnext_v2bc --num_classes 3 --img_size 224 \
  --seed 42 \
  --data-path-train ./datasets/cle_ac_v1/train \
  --data-path-val   ./datasets/cle_ac_v1/val \
  --weights /home/login/data/cle/sunfuxiang/classifyML/pth/convnext_tiny_1k_224_ema.pth \
  --save-dir ./weights_v2bc_seed42 --epochs 300
```

ImageNet 权重经 `MODEL_CHECKPOINT_TRANSFORMS["convnext_v2bc"]`（`_remap_wr`）
把 `dwconv.{weight,bias}` 重映射进 `WTConv.base_conv.*`，严格加载审计
`unexpected=0`。

## 5. 评测（全指标）

```bash
python evaluate.py --model convnext_v2bc \
  --weights ./weights_v2bc_seed42/<run目录>/model_best.pth \
  --data-path ./datasets/cle_ac_v1/test
```
