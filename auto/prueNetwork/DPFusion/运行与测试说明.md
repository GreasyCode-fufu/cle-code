## 3. 测试

### 3.1 模型构建自测（无需任何权重）

```bash
./run.sh python -c "
import torch
from cle_fair_common import build_model
m = build_model('cle_convnext_sn', num_classes=3).eval()
print(tuple(m(torch.randn(1,3,224,224)).shape), sum(p.numel() for p in m.parameters())/1e6, 'M')
"
# 期望：(1, 3) 27.82 M
```

### 3.2 一键自检（需上面复制的两个最优权重 + 数据集）

```bash
./run.sh python self_test.py
# 期望输出：SN 0.9740 / Fusion 0.9721（构建模型 + 复现两个 test 指标）
```

### 3.3 评测推荐模型

```bash
./run.sh eval --model cle_convnext_sn \
    --weights ./weights/sn_best/model_best.pth \
    --data-path ./datasets/cle_ac_v1/test --out-dir ./eval_out/sn
# 输出 11 项指标 + 复杂度 + FPS
```

### 3.4 双先验决策级融合推理

```bash
./run.sh python scripts/predict_fusion.py \
    --lcn-weights weights/lcn_best/model_best.pth \
    --sn-weights  weights/sn_best/model_best.pth \
    --data-path   ./datasets/cle_ac_v1/test --out-dir ./eval_out/fusion
```

### 3.5 批量评估 / 主干对比表

```bash
./run.sh python scripts/eval_all.py         # 批量评估并聚合 11 指标
./run.sh python scripts/table_backbones.py  # 生成主干对比表
```

## 4. 重新训练（与论文协议一致：224 / bs32 / AdamW 1e-4 / wd 5e-2 / Cosine 300ep）

```bash
./run.sh train --model cle_convnext_sn --num_classes 3 --img_size 224 --seed 42 \
    --data-path-train ./datasets/cle_ac_v1/train \
    --data-path-val   ./datasets/cle_ac_v1/val \
    --weights /home/login/data/cle/sunfuxiang/classifyML/pth/convnext_tiny_1k_224_ema.pth \
    --save-dir ./weights_new --epochs 300
```

权重审计应输出 `strict load passed ... unexpected=0`（SN 的 `log_gain` 在
白名单内，恒等初始化）。

其他可用模型名（本包注册表内实际可用）：`cle_convnext_sn` / `cle_convnext_lcn_only`
/ `cle_convnext_dpf` 等以 `convnext_*`、`cle_convnext_*` 开头者；其余名字指向
未随包复制的模块（惰性导入，不影响上述名字）。
