# R6 模块库筛选记录 (module_library, 2026-11-08)

目的: 为 MobileNetV3-L 轻量 CLE 网络筛选可借鉴的库内机制。原则: **按源码判定真实机制(不信文件名)**,
借机制 + CLE 数据动机 + mbv3 适配 + 轻量实测 + 置零归因, 不做"即插即用缝合"。

## 1. 硬性过滤条件
1. **轻量/可部署**: 仅 conv / dw / 1×1 / 池化 / 逐元素; 排除 FFT/小波、≥/8 分辨率的 softmax 注意力、
   unfold 密集、sort/randperm/topk 路由、动态 shape(ONNX/TFLite 不友好)。
2. **非已证伪家族**(R3–R5 在 ConvNeXt 上 25 候选证伪): SE 及变体、GRN、TeLU、WTConv/频段重加权、
   多膨胀卷积、二阶(协方差)池化、注意力池化头、自上而下门控、PFESA(223)、SDGW(233)。
3. **CLE 数据动机**: B/M 判别在腺体结构规则性与局部异质性; 纹理各向同性; ~25–31% 圆形视野外暗背景。
4. **mbv3 适配**: 可零初始化(初始与预训练逐位等价)或位于本就冷启动的分类头。

## 3. 结论(与 P0 数据分析交叉)
- 创新1(头部): **StarNet 星运算 → 跨尺度星乘证据头**。P0 证实头部是最大瓶颈(线性探针 +1.3 F1/+4.0 sens_M),
  且 ImageNet f12(/16) 的 B-vs-M AUC 0.997 最高 —— 头部应直接消费 /16 证据。
- 创新2(/16 主干模块): LSConv(局部动态聚合) vs IDC(大感受野) 同批快筛, 由数据裁决。
- 创新3(训练期先验, 推理零成本): MatchED 式边缘先验的 P0 动机偏弱(微调仅使 /16 边缘可解码性 R² −2.1pt);
  并列一个由 P0 直接支撑的候选(/16 预训练证据锚定, 见 R6_DESIGN.md), 同批快筛。
- 文件名与真实机制不符的情况较多(10/40 为换名 SE/CBAM/ECA), 论文引用一律按真实原始出处。
