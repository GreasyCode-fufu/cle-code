# R3 数据分析 — cle_ac_v1 全量 3080 张原生分辨率统计 (2026-11-08)

脚本 `c_data_analysis.py`(58s, 8进程) → `c_data_analysis.json`；图 `c_figs/`。
背景：11-01 的 `cle_image_analysis.py` 只在 224 分辨率上每类采样 120 张，本轮补原生分辨率与全量核查。

## Q1 划分与亚型（患者级干净）
- 尺寸 760–816 × 780–804，全 RGB JPEG；train/val/test = 2077/427/576。
- 样本 ID（文件名 S_xxx）跨划分重叠 = **0**，md5 完全重复 = 0。dHash≤4 近重复共 67 对，其中跨划分 12 对（test↔train 10 对）且 5 对标签冲突——同一视野不同帧归入不同类目录/划分（如 test 良性 atrophy 与 train 恶性 dysplasia 视觉近重复）。比例小（12/3080），不动数据（保持与历史全部结果可比），但说明 **test 存在天然难样本，提升空间集中在难样本而非数据噪声**。
- 亚型命名归属：test 中 20 张 atrophy 帧被标为 Malignant（val 也有 6+5 张交叉标注）——**类内异质性大，网络需要亚型鲁棒特征**。

## Q2 成像与强度（±为标准差）
- **近黑背景**：全图均值 ~0.24–0.27，暗像素占比 24–31%（N 类最高 0.29），四角均值 = 0（方形画幅内嵌圆形 FOV，无黑边裁剪）。→ 模型不需要处理 vignetting，但 **~25% 像素是无信息暗区**，GAP 会被稀释。
- 类间亮度差存在（test: B 0.271 / M 0.234 / N 0.207）但组内标准差 ±0.05–0.07，重叠大。
- 无饱和（sat≈0），对比度 std≈0.20–0.23 类间接近。

## Q3 频谱（原生 768²中心裁剪，Hann 窗）
- 能量极度低频集中（低 8% 半径占 >95%）。
- **800→256 缩放仅丢失 0.06–0.11% 能量**（800→448 更少）——核级细节能量占比小，"上分辨率"方向收益有限（但视觉对比图 c_figs/native_vs_resized.png 显示核点在 256 缩放后确实趋于消失，作用应在形态而非频谱能量）。
- 径向谱 B/M/N 三类曲线几乎平行（M 全频段略低），**类间差异是全局统计量级别的，不是某个频段独有**。

## Q4 方向性
- 梯度各向异性指数仅 0.07–0.09（≈各向同性）→ 腺体无主导方向，**旋转不变假设成立**，方向类算子（条带卷积）动机弱。

## Q5 低层统计可分性（train, one-vs-rest AUC）
- **p01（1% 暗分位）AUC = 1.0 完美区分 B/M vs N**——暗区比例是最强的"平凡"特征，网络很可能已轻松利用；**B vs M（真正的临床难点）所有低层统计 AUC 仅 0.50–0.66**，std 最高 0.661。
- → **创新必须作用在结构/纹理组织层面（腺体形态、排列规则性、局部异质性），而不是全局统计或单一频段**；这与视觉分析一致（atrophy↔IM↔dysplasia↔cancer 是"规则→紊乱"的连续谱）。

## Q6 视觉判读（c_figs/samples_by_subtype.png，视觉模型逐行判读）
- 良性侧（atrophy/IM）：腺体仍离散、轮廓规则，IM 有刷状缘细纹；恶性侧（dysplasia/cancer）：腺体分支/融合/排列紊乱、局部异质性强；normal：圆形腺体规则排列、最干净。
- 最难边界 = **dysplasia↔IM/cancer（结构紊乱程度连续）与 atrophy↔normal**——正是 SF 19 个 test 错误的分布（atrophy→M 6 例最多）。

## 设计启示（对 R3 创新）
1. B/M 判别靠"结构规则性 + 局部异质性"，二者都是**空间组织**属性 → 有前景的方向：腺体形态统计（局部极值/斑点组织）、排列各向同性下的多方向结构响应聚合、局部异质性（区域间差异）显式建模。
2. 暗区占 1/4、p01 完美区分 N → **背景感知的证据池化**（只在有效组织区域聚合）可能帮助 B/N 边界（当前 12 个错误）与恶性召回。
3. 频段能量类方向（前作 WR 及姊妹项目 FGC/EGB 系）已充分探索且同批增益有限；**避开频域算子，转向空间结构/选择性聚合**。
4. 类内亚型异质（atrophy 既在 B 也在 M）→ 特征层面需要"判别区域聚焦"而非全图均匀混合。
