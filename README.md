# 三 Agent 协作炼丹平台 (zcode / Doubao / Workbuddy)

## 总任务与授权(用户原话, 2026-10-23, 三方共同遵守)
- 任务: 参考模块库与自主设计, 在 resnet34(或其他 models 内 baseline)基础上魔改,
  自动化实验->分析->迭代, 直到测出好的结果或模块最优出现位置。
- GPU: 4090 可无限制使用; 显存充足, 技术可行可多条实验并行(三方分摊后约定单Agent并发<=2)。
- 预算: 跑到最好的结果出现为止, 没有时间限制。
- 成功标准: 测试集(test) macro-F1 超过 baseline >= 1.5 个百分点(vanilla 三种子均值 0.8814,
  即目标线 0.8964), 且需三种子稳健确认。以测试集为准(用户明确指定), 但选模仍用 val。
- 允许测试 models 中其他主干/基于其他 baseline 改进(主干扫描已由 zcode 完成, 结论见下)。

## 目录
- TASK_BOARD.md      任务认领板(防重复工作, 开新实验前必读必写)
- results/           各 Agent 实验结果(各自维护 zcode.csv / doubao.csv / workbuddy.csv)
- findings/          重要发现(一个发现一个 md, 文件名: 日期_agent_主题.md)
- announcements/     公告(启动长任务批/协议变更前发一个 md)

## 工作流(每批实验)
1. 读 TASK_BOARD.md, 确认要做的方向没人认领
2. 在 TASK_BOARD.md 认领区追加一行(时间戳+Agent+方向+预计时长)
3. 在自己的工作区实现并跑实验(用本工作区的 experiments/runner.py)
4. 结果追加到 results/<自己>.csv; 重要发现写 findings/
5. 完成后在 TASK_BOARD.md 勾选完成并写一行结论

## 硬规则
- 只改自己工作区; 共享区只追加, 不删改他人内容
- 新模型注册名加自己前缀: Doubao=db_, Workbuddy=wb_ (zcode 保留原名)
- 单 Agent 并发训练 ≤2 (三方同时跑也不超载 4090)
- 结论以 3 种子(42/43/44) test macro-F1 均值±标准差为准, 禁止单种子报喜
- 目标线: 3 种子均值 ≥ 0.8964 (vanilla 基线 0.8814 + 1.5pt)
- 各自工作区改动必须 git 提交; 评估结果必须从 weights/<model>_seed<seed>/ 下
  按 results.json 的 test_dir 字段读取(区分 val/test, 踩过的坑, 勿重蹈)
- 训练协议不可改(AdamW lr1e-4 wd0.05 / Cosine / AMP / b32 / 300ep早停30 /
  macro-F1 选模 / ImageNet 归一化), 保证三方结果可比; 分辨率/平滑等超参
  属于合法实验维度, 但需在 TASK_BOARD 注明

## 基准(随种子数更新; 判定用同种子集配对比较)
- vanilla resnet34: 3种子 0.8814±0.0074; **5种子(42-46) 0.8857±0.0067**
- 注意: 基线随种子数收紧后, dil234 的优势从+0.95pt缩至约+0.5pt; 后续结论一律用
  相同种子集的均值对比, 目标=基线均值+1.5pt(5种子口径即≥0.9007, 旧线0.8964作最低线)
- 当前冠军 resnet34_msec_dil234(zcode): 0.8909±0.0101
- pvt_tiny: 0.8816±0.0111 | 已证伪: SE/PFESA单用/条带/边缘分支/layer2插入

## 无人值守自驱模式(2026-10-23 起)
- 三Agent各自定时自驱(约每30-45分钟一轮): 查自己批次结果->分析->设计并启动下一批->更新
  TASK_BOARD->写心跳到 announcements/heartbeat_<agent>.md
- 不再需要用户转发消息; 用户只保持各客户端开启
- 冲突规则: 同方向认领以 TASK_BOARD 时间戳先者为准; 发现撞车则让先者、换方向
- 汇报纪律: 每轮心跳一行(时间+批次+状态); 重要发现写 findings/; 重大成果或协议级
  问题写 announcements/ 并在自己的循环里暂停该方向
- 成功判定: 某方案在与 vanilla 相同种子集上 test 均值 >= 基线均值+1.5pt -> 发
  announcements/BREAKTHROUGH_*.md, 各Agent停止自动循环, 等用户回来验收
- GPU 礼让: 单Agent并发<=2; 若发现服务器异常(OOM/磁盘满), 在公告说明并暂停自己批次

## 队列深度规则(2026-10-23 23:2x 补充, 减少批次间隙空窗)
- 每次自驱唤醒时, 保证自己队列中未完成任务 >= 4 个(一次设计一打更好)
- 批次边界空窗是 GPU 空闲的主因; 宁可排队等 GPU, 不要让 runner 断粮
- 唤醒周期建议 20-30 分钟

## 种子规则(2026-10-23 23:3x 用户指令, 覆盖此前口径)
- 任何实验最多跑 3 个种子(42/43/44), 不许多跑、不许加 45/46 等
- 结果记录口径: 三种子中的最优值(best-of-3); 全部种子明细仍照记 CSV 备查
- 成功判定: 方案 best-of-3 >= vanilla best-of-3 + 1.5pt
  vanilla best-of-3 = 0.8888(seed44) => 目标线 0.9038
- 旧均值口径(0.9007/0.8964)仅作参考, 不再作为判定依据
