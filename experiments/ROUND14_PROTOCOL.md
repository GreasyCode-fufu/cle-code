## Grader, confined to each outer training fit set

The fixed R9 DINO CLS+patch-mean768 features are reused without neural updates. These public encoder features contain no CLE supervised fine-tuning. For each original outer job, exclude its entire inner-select and outer-score patient sets from all grader fitting, transformations and grading. Within that job's fit patients run SGKF5 for each fixed replicate42/43/44, random_state=outer_seed*100000+outer_fold*100+replicate. Thus every fit image has exactly3 predictions from heads excluding its whole patient group. There are15 outer grade units and225 convex linear fits, zero new neural grader training.

Each head: multinomial LogisticRegression, C=1, l1_ratio=0, solver=lbfgs, intercept, max_iter2000, tol1e-6, no class weights. Standardization mean/std(ddof0), floor1e-6, estimated only from that head's training patients. No tuning, temperature calibration, or outer labels in head fitting. Save all225 heads, transforms, fit/held indices and SHAs. A convergence warning or gradient residual>5e-5 stops the unit for an explicit repair; it does not silently accept an invalid fit. API reference: https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html . These are model-consistency probabilities, not calibrated quality truth.

Use immutable core.grade on correctness fraction across3 predictions and mean probability of the EXISTING label: A both>=.95; B both>=.85; E either<.30; D either<.60; otherwise C. These are the original cutoffs, without threshold tuning. The grader differs from the original supervised-CNN grader and tests this stated operationalization, not exact equivalence to human grading or proof of label noise. No grades outside the fit set are generated.
