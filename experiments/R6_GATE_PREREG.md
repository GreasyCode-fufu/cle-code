# R6 可迁移性门控 —— 预注册（2026-11-09 03:15, 在查看 TCGA 任何 test 结果之前提交）

## 背景
泛化实验显示创新 ①（证据保持冻结 /2–/16）具有域依赖性: 在 CLE 上 +1.0（相对 ②+③）, 在小样本超声/X 光域有害。
LP-FT 理论（Kumar et al., ICLR 2022）: 当冻结特征的线性探针已接近全量微调时, 微调主要带来特征失真 —— 冻结更优。

## 门控规则（只用 train/val, 不读 test）
- LP_val: 冻结 ImageNet mbv3 四尺度 GAP 特征 + 强 L2 逻辑回归（C 在 val 上选）的 val Macro-F1（`r6_transfer_probe.py`）。
- FT_val: baseline mbv3 全量微调（原协议）各 seed val Macro-F1 的均值。
- **gap = FT_val − LP_val; gap ≤ 1.5 → 启用 ①（最终网络 = ①+②+③）; gap > 1.5 → 不启用（最终网络 = ②+③）。**
- 阈值 1.5 取 5 个已观察域中"冻结有益"最大 gap（covid 0.97）与"冻结有害"最小 gap（BUSI 2.19）的中点 ——
  **它是在这 5 个域上拟定的, 因此 TCGA 作为唯一的样本外检验**。

## 修订 v2（2026-11-09 04:30, 仍在 TCGA 任何结果产生之前: TCGA baseline 尚在训练, 无 val/test 结果）
**原因**: CUB 上门控(v1)启用 ①, 但 ①+②+③ 64.95 < 不冻结 ②+③ 66.39, 而纯冻结 ImageNet 线性探针 test 更达 67.98 ——
当冻结特征在 val 上已**优于**全量微调(gap < 0)时, 连 /32 段也不该微调。v1 只有"冻结 /2–/16 或全量微调"两档, 深度粒度不足。

**门控 v2（三档, 只用 train/val）**:
- gap ≤ 0（冻结特征已不劣于全量微调）→ **全保留**: 不做阶段 1 训练, 直接在纯 ImageNet 主干上做阶段 2（LP 臂, `mbv3_lp_dce4m`）;
- 0 < gap ≤ 1.5 → **① 冻结 /2–/16** + ②③（`mbv3_fz16_dce4m`）;
- gap > 1.5 → **全量微调** + ②③（`mbv3_dce4m`）。

已观察 5 域在 v2 下的决定: CUB(−6.11) → 全保留; CLE(+0.61)、covid(+0.97) → ①; BUSI(+2.19)、heelBone(+2.65) → 全量微调。
v2 的两个阈值（0 与 1.5）都在这 5 域上拟定; **TCGA 仍是唯一样本外检验**。判定标准（预先写定）: 门控所选档位的 test F1
是否为三档中最高（或与最高者相差 < 0.3）, 以及是否优于 baseline。
