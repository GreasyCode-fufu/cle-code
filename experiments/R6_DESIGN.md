# R6 设计文档 — MobileNetV3-L 轻量 CLE 网络（2026-11-08）

> 代码: `models/optimize/mbv3_cle_r6.py`; 数据分析: `experiments/r6_p0_analysis.py` → `r6_p0_analysis.json`;
> 模块库筛选: `R6_MODULE_SCREEN.md`; 冒烟: `smoke_mbv3_r6.py` / `smoke_mbv3_r6_ac.py`; 测速: `r6_bench_latency.py`。

## 0. 目标与约束（用户已确认）
- 基座 MobileNetV3-Large（torchvision IMAGENET1K_V1, 4.21M / 0.23G）；同批 baseline 3 seeds 逐位复现历史
  （94.94/93.88/93.42, 均值 94.08）。创新点 2–3 个链式叠加；任一 evaluate.py 指标 3-seed 均值 +0.5~1.0 达标。
- **轻量守则**：部署参数力争 ≤ baseline（上限 +10%），MACs ≤ +5%，CPU 单线程延迟 ≤ +10%；
  仅 conv/dw/1×1/池化/逐元素算子；训练期专用模块允许（推理不执行、不计入部署参数）。
- **新颖性**：不复用 GEM-ConvNeXt 的 MSP/DCH/FGS 作创新点；借模块库机制 + CLE 动机 + mbv3 适配。

## 1. P0 证据链（决定设计优先级）

|---|---|---|---|
| F1 | **头部是最大瓶颈** | 同一微调 f16 特征: 正则化线性头 vs 网络自身 1.23M MLP 头 test F1 95.37 vs 94.08 (+1.3), sens_M 93.0 vs 89.0 (+4.0), 3 seeds 配对全正; AUC_BM 0.986 vs 0.984 持平; val 选出的正则强度触网格下界(C=0.003) | 冷启动宽 MLP 头过拟合、决策面差 → 头部需轻、需更好的归纳偏置 |

## 2. 创新点设计

### 创新 1 — 跨尺度星乘证据头（CSE head）【对应 F1+F2】
- **结构**：`u = LN(W_u·GAP(f16)) ∈ R^256`，`v = LN(W_v·GAP(f12)) ∈ R^256`，`z = [u, ReLU6(u) ⊙ v]`，
  `logits = W_o·Dropout0.2(z)`。替换原 960→1280→K MLP 头。
- **数学性质**：`(ReLU6(u)⊙v)_k = ReLU6(w_u,k·p16)·(w_v,k·p12)` —— 每维是 /32 语义证据与 /16 结构证据的秩-1
  双线性形式，256 维合起来 = 低秩分解的跨尺度双线性池化（Kim et al. ICLR'17 Hadamard 低秩双线性；
  StarNet 的"星运算隐式高维"论证）。以 O(d) 代价得到跨尺度二阶交互，取代以宽度换容量的 1280 维隐层。
  ReLU6 门使交互项有界，配合 LN 保证乘积尺度稳定（AMP 安全）。
- **参照**：模块库 9 StarConv（StarNet, CVPR'24）—— 块内同尺度 `act(x1)*x2` 改为头部跨尺度证据交互。
  与 GEM 的拼接式 DCH（加性、稠密 Linear）机制不同。
- **预训练兼容**：头部在本协议下本就冷启动；主干逐键严格加载，主干输出与 baseline 逐位一致（冒烟 max|Δ|=0）。
- **成本**：参数 4.206M → **3.249M（−22.7%）**；MACs 0.233G → 0.232G。
- **对照行（归因）**：`lin`（线性头）、`mlp256`（同宽加性 MLP, 0.247M）、`star1`（同尺度星乘, 仅 f16）、
  `star3`（再加 /8 f6）。若 `mlp256≈star2` → 增益来自"缩头"而非跨尺度星乘，需重新论证。

### 创新 2 — /16 结构感知局部聚合（候选同批快筛）【对应 F2】
接在 `features[12]`（/16 末端, 112ch@14²）之后，零初始残差 `y = x + BN_{γ=0}(Agg(x))`（初始与创新 1 网络逐位等价）。
- **LSAgg**（模块库 122 LSConv, LSNet "See Large, Focus Small", CVPR'25, 轻量网络论文）：大核感知 LKP
  （1×1→7×7dw→1×1→1×1+GN）为每个位置生成 3×3 动态核（每 8 通道共享，官方分组形式；库版改为逐通道 ×8 参数，不采用），
  小核聚合 SKA 以 9 次平移乘加实现（确定性、可导出）。动机：腺体排列需要大范围上下文（see large），判别在局部
  结构的规则/紊乱（focus small）；动态核在规则区趋同、紊乱区分化 = 局部异质性的显式传感。+20.1K / +1.7% MACs。
- **IDCAgg**（模块库 16 InceptionNeXt IDC, CVPR'24）：3×3 / 1×11 / 11×1 分解 dw + 1×1，大感受野对照。+13.9K / +1.2%。
- **接入位置**：`bb`（进主干，喂 /32 与头部 /16 证据）vs `side`（只进头部 /16 证据通路，主干不变）。
- **配对隔离**：新增模块在独立 RNG 中构建，同 seed 下与创新 1 网络数据顺序/增广/Dropout 掩码完全一致（冒烟验证）。
- **归因测试**：训练后将 `r6agg.bn.γ` 置零重评，增益须随之消失。

### 创新 3 — 训练期先验（推理零成本，候选同批快筛）
经 train_cle_fair 既有钩子 `loss += model.mfm_lambda * model.mfm.loss` 接入，推理时不执行、不计入部署参数。
- **anchor（/16 预训练证据锚定）**【对应 F2】：冻结的预训练 `features[0..12]` 参照网络（checkpoint 变换注入，
  BN 与学生同用 batch 统计量但 momentum=0 永不更新 → 初始锚定损失恰为 0，之后只反映权重漂移），
  损失 `λ·||f12 − f12_ref||² / ||f12_ref||²`，λ ∈ {1.0, 0.3}。理论参照：L2-SP（ICML'18）、LP-FT 特征扭曲论（ICLR'22）；
  区别在于只锚定判别证据所在的 /16 尺度、并与消费 /16 证据的头部协同。
- **edge（MatchED 式边缘先验，对照）**【对应 F5】：模块库 175 MatchED（CVPR'26）紧凑边缘头在 /16 回归 FOV 内 Sobel
  边缘密度（逐图 z-score），λ=0.2；soft-chamfer 面向全分辨率细边，14² 上改为密度回归。

## 3. 实验流程与判定规则
- **MA 批**：baseline×3 + star2/lin/mlp256×3 + star1/star3×2（同批同协议，结果 `results_cle_ac_v1_r6.csv`）。
- **MB 批**：最佳头 + 创新 2/3 候选各 ×2 seeds（并行快筛，链式确认）。
- **入选第 3 seed**：2-seed 配对均值 ΔF1 ≥ +0.3，或 Δsens_M ≥ +1.5 且 ΔF1 ≥ −0.1。
- **保留进链**：3-seed 配对均值 ΔF1 > 0 且 ≥2/3 seed 为正（或临床判据：sens_M 显著提升且 F1 持平）。
- 组合回退是常态 → 每步独立成行，回退即换候选；最终链 baseline → +创新1 → +创新2 → +创新3 全部 3 seeds 同批。
- 所有比较按 seed 配对（管线确定性已再次验证：同批 baseline 与 10-26 历史逐位一致）。

## 4. 风险与预案
- 头部增益若主要来自缩头（mlp256≈star2）：改以"轻量化头 + 跨尺度证据"叙事，并考虑归一化（余弦）头抑制决策面过拟合。
- 线性头端到端不稳（MA 首批 lin s42 91.14）：说明探针优势依赖强正则 + 固定特征，端到端须由结构提供归纳偏置。
- 动态核/零初始分支萎缩：归因测试兜底；必要时改为 side 通路（被头部直接消费，不可旁路）。
