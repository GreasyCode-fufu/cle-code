# 固定A–C验证集纹理与错误证据：CPU诊断预注册

本轮无新网络训练。所有图像访问仅固定2077个train索引与427个val索引，不读576个test图像或test逐图概率，不重分级/筛图/改标签/阈值。物理cache有3595行，逐次访问白名单、split计数、索引SHA完整记录。模型选择已有历史test依赖，故此诊断也不称独立或无筛选依赖验证，更不是患者OOF。

目的：用已训练固定B0、原M方向矩及本轮完整三seed mom_corr的验证预测，检查方向矩收益与跨尺度相关失败可能集中在哪些图像统计条件，为下一机制提供可复核的描述依据。保留全部三seed，checkpoint均按原val最早最高macroF1选择；不训练/挑新权重。

只定义四个无标签图像统计量，全部在固定原cache的256图像中心224×224、原始RGB均值/255上计算：灰度均值、灰度总体标准差、相对细节能量、梯度各向异性。相对细节能量=sqrt(mean((g−reflect边界5×5均值滤波(g))²))/(std(g)+1e-4)。梯度取中心差分、共同内部222×222，Jxx/yy/xy为空间平均梯度积；各向异性=sqrt((Jxx−Jyy)²+4Jxy²)/(Jxx+Jyy+1e-8)。这些是整个裁剪图的统计量，包含背景，不等同医生判定的组织质量、病理结构或细胞量。

对每个统计量，低/中/高三组阈值仅由固定train2077张的1/3与2/3分位数（NumPy linear）计算，不用标签、val/test分数优化。阈值只是诊断分箱，不改变A–C等级、数据选择或训练阈值。四统计×三箱全部报告，不能只挑显著组。统计描述有多重探索依赖且错误数少，不宣称分组因果贡献；不对小样本箱制造显著性结论。

每组报告图片/患者/三类数量、全部seed的macroF1与accuracy、患者等权accuracy、恶性召回、混淆矩阵；配对报告原M方向矩对B0、mom_corr对方向矩的纠正/损伤数和平均差。全验证集另报告39患者20k配对bootstrap，两种数值路径与前5次直接重采样交叉核对，区间仅条件描述，不作外部确认。患者可多标签，不强制单患者诊断。

分析前先冻结源、data manifest、模型完成标记/实际checkpoint SHA、逐图val概率SHA及配置入Git，再运行CPU数值检查。独立审计：原图统计5×5直接窗口及常量/90度旋转数值性质，原始概率/整数Fraction混淆矩阵宏F1、患者等权准确率独立循环、白名单/全2504索引与split计数、指标有限、阈值只train复算。当前GPU结构轮按既定计划继续，全部控制结果齐备后再综合判断。
