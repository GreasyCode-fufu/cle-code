# 2 方法

## 2.1 任务分析、总体架构与设计原则

共聚焦激光显微内镜（confocal laser endomicroscopy, CLE）可在体获得约 1000 倍放大、近组织学分辨率的消化道黏膜显微图像。本文将其形式化为三分类问题：良性病变（Benign）、恶性病变（Malignant）与正常胃底体黏膜（Normal）。CLE 图像的判读依据（Mainz 分类体系）集中于两类线索：

1. **腺体结构规则性**——良性/正常腺体呈圆形或椭圆形、大小一致、排列整齐；恶性腺体大小不一、融合、排列紊乱。这是**中低频、跨尺度**的结构性模式：单个腺体的轮廓（高分辨率层）与腺体簇/黏膜架构（低分辨率层）同时携带判别信息；
2. **细胞级细节**——核增大、荧光增强、核浆比升高、极性紊乱与细胞边界破坏，属**高频、细粒度**的局部纹理线索。

对基线 ConvNeXt-T 的结构审视揭示两个与上述线索直接冲突的设计：**(i)** 每个 block 的 token 混合器为单一 7×7 深度卷积，感受野与频带响应固定，难以同时覆盖跨尺度的腺体自相似结构；**(ii)** 分类头仅对最深 stage（stage-4，7×7 分辨率）的特征做全局平均池化，细胞级细节所在的中高层证据（stage-2/3）在分类前即被丢弃。

据此，本文提出 **SF-ConvNeXt（Scale–Frequency-aware ConvNeXt）**，在 ConvNeXt-T 上做两处结构化改造：

- **WR（Wavelet-Replace Block，频域多尺度卷积块）**：将 stage-3/4 全部 12 个 block 的 7×7 深度卷积**整体替换**为 WTConv 算子——由直接继承预训练权重的 7×7 基卷积分支与 Haar 小波级联路径构成，使感受野按分解级数指数扩展并具备频带选择性（§2.2）；
- **CH（Concat multi-scale Head，三尺度拼接分类头）**：分类头输入改为 stage-2/3/4 三级特征经 1×1 投影与池化后的拼接向量，从结构上强制分类器消费跨尺度证据（§2.3）。

两项改造遵循三条设计约束：

**(D1) 预训练兼容。** 除被替换组件外，ConvNeXt 全部参数的键名保持不变；被替换的 7×7 深度卷积权重经键重映射（`stages.{2,3}.*.dwconv.* → …dwconv.base_conv.*`）迁移至 WTConv 的基卷积分支，ImageNet-1k 预训练权重经严格审计（任何非白名单键缺失/多余即终止训练）完整加载。

**(D2) 不可旁路（non-bypassable）。** 我们在预实验中系统考察了"零初始化门控并联注入"这一常用的即插即用集成方式（记为门控加法式，§3.4），发现其存在失效模式：训练完成后门控范数仅 10⁻³ 量级，推理时将门控置零，测试 Macro-F1 变化不超过 ±0.35 个百分点且方向不定——即主干可以把并联分支"旁路"掉，模块并未真实承载判别计算。因此本文所有创新点均采用**替换式**集成：WR 中 7×7 基卷积与小波路径相加重构、二者缺一不可；CH 中每个 logit 必须读取全部三尺度拼接输入。§3.4 的组件移除干预实验证实了这一设计的有效性。

**(D3) 轻量。** 两项改造合计仅增加 0.87M 参数（27.80M → 28.67M，+3.1%）与 0.19G MACs（4.45G → 4.64G，+4.3%），推理吞吐仍达 364 张/秒（batch=1），远超实时诊断需求。

## 2.2 频域多尺度卷积块（WR）

记 block 输入特征 $u\in\mathbb{R}^{C\times H\times W}$。原 ConvNeXt block 的空间混合为 $u\mapsto \mathrm{DWConv}_{7\times7}(u)$。WR 将其替换为

$$
\mathrm{WTConv}(u)=\underbrace{\gamma_b\odot \mathrm{DWConv}_{7\times7}(u)}_{\text{基卷积分支(继承预训练)}}+\underbrace{\mathcal{IW}\Big(\Psi_2\big(\mathcal{W}_2\,\Psi_1(\mathcal{W}_1 u)\big)\Big)}_{\text{Haar 级联小波路径}},
$$

各部分定义如下：

- **Haar 分解** $\mathcal{W}_l$：对作用于第 $l$ 级的低频子带执行二维 Haar 离散小波变换（固定分析滤波器组，无学习参数），得到 $\{\mathrm{LL},\mathrm{LH},\mathrm{HL},\mathrm{HH}\}$ 四子带，空间减半、子带数 ×4；
- **子带卷积** $\Psi_l$：对全部 $4C$ 个子带施加 3×3 分组深度卷积（分组数 = 4C），并配可学习逐通道尺度 $\sigma_l$（初始 0.1）；
- **逆变换** $\mathcal{IW}$：Haar 重构（合成滤波器为分析滤波器的伴随算子），恢复原分辨率。

设计动机与性质：(i) 两级级联下，子带卷积的 3×3 核作用于逐级减半的子带上，**等效感受野随级数指数增长而参数仅线性增加**，以近似零成本覆盖腺体簇尺度的上下文；(ii) 级联分解反复作用于低频子带，使算子天然强调**形状/结构**信息（对应腺体架构规则性），而基卷积分支保持局部**高频**响应（对应细胞核细节），二者互补；(iii) 基卷积分支直接加载该 block 的预训练 7×7 权重（$\gamma_b$ 初始为 1），小波路径以 10% 初始幅度参与，兼顾预训练知识迁移与新频域容量引入。

替换范围限于 stage-3/4（共 12 块）：消融实验（§3.3）表明将替换扩展到 stage-2 会损害性能——浅层细纹理通路应保持预训练原样，深层的结构判别才是多尺度上下文的受益位置。块内其余路径（LayerNorm → 1×1 升维(4C) → GELU → 1×1 降维 → LayerScale → 随机深度残差）与原 ConvNeXt 完全一致。

## 2.3 三尺度拼接分类头（CH）

原分类头 $\hat y=\mathrm{Linear}(\mathrm{LN}(\mathrm{GAP}(f_4)))$ 仅使用最深 stage 特征。CH 将头输入改为三级拼接：

$$
v=\big[\underbrace{\mathrm{LN}_4(\mathrm{GAP}(f_4))}_{\text{语义/架构证据}};\ \underbrace{\mathrm{LN}_3(\mathrm{GAP}(P_3 f_3))}_{\text{中层结构证据}};\ \underbrace{\mathrm{LN}_2(\mathrm{GAP}(P_2 f_2))}_{\text{细胞纹理证据}}\big]\in\mathbb{R}^{2304},
\qquad \hat y=\mathrm{Linear}(v),
$$

其中 $f_i$ 为 stage-$i$ 输出，$P_3\in\mathbb{R}^{768\times384}$、$P_2\in\mathbb{R}^{768\times192}$ 为无偏置 1×1 投影，$\mathrm{LN}_4$ 复用预训练的最终 LayerNorm（保持深层特征的预训练统计），$\mathrm{LN}_2,\mathrm{LN}_3$ 为新引入的 LayerNorm。由于分类器权重与全部 2304 维输入稠密相连，跨尺度证据融合在结构上不可旁路；新增参数仅 0.45M（投影 + 归一化 + 头部）。

## 2.4 实现与训练协议

所有模型（含全部对比网络与消融变体）在完全相同的协议下训练以保障公平：AdamW（lr = 1×10⁻⁴，weight decay = 5×10⁻²），余弦退火（T_max = 300），批大小 32，输入 224×224，AMP 混合精度；训练增广为 256² resize + 水平/垂直翻转 + ±15° 旋转 + 随机裁剪；预训练模型使用 ImageNet 归一化。以**验证集 Macro-F1** 选择最优 checkpoint（早停耐心 30，最多 300 轮）。预训练加载采用严格审计机制：除分类头与显式白名单段（新模块参数）外，任何键缺失或多余立即报错终止，杜绝静默权重错配。每个关键配置以固定种子（42/43/44，基线另加 45/46）独立重复训练，报告均值±标准差与最优单次结果。硬件：单卡 NVIDIA RTX 4090（49GB）。

# 3 实验与结果

## 3.1 数据集与评价指标

**数据集 cle_ac_v1**（患者级划分的 CLE 胃黏膜三分类数据集）：训练集 2077 张（良性 830 / 恶性 371 / 正常 876）、验证集 427 张（195 / 79 / 153）、测试集 576 张（208 / 176 / 192）。恶性类仅占训练集 17.8%，类别不平衡显著，且错误分析（§3.6）显示判别难点集中于良性↔恶性边界——正是 §2.1 所述两类线索交织之处。

**评价指标**（evaluate.py 标准协议：Resize→CenterCrop 推理、与训练一致的归一化、thop 复杂度统计）：以 **Macro-F1** 为主指标（类别不平衡首选），同时报告 Accuracy、Weighted-F1、Balanced Accuracy、Macro-Sensitivity、Macro-Specificity、Macro-AUROC(OvR)、Cohen's Kappa、MCC 共 9 项总体指标及逐类 Sensitivity/Specificity/Precision/F1/AUROC；对最终模型最优 run 额外给出 1000 次 bootstrap 重采样的 95% 置信区间。

## 3.4 机制分析：从"可旁路门控"到"结构化融合"

为验证创新点的贡献机制，我们进行了三组可证伪检验。

**(1) 门控加法式设计的失效（预实验）。** 我们首先按流行的即插即用范式实现了零初始化门控并联版（茎干小波分支、WTConv 并联分支、多尺度门控注入头，记为 v1 系列）。训练后各门控向量范数仅 0.001–0.003（对照：原 ConvNeXt LayerScale γ 均值 0.94）；在测试集上实测各注入项相对主干特征的 L2 贡献比为 0.05%–0.4%；将全部门控置零（数学上退化为同权重基线），4 个种子的测试 Macro-F1 变化为 -0.35 / 0.00 / 0.00 / +0.35pt，预测翻转仅 0–2/576 张。结论：门控加法式分支被权重衰减压向恒等映射，其表观提升不可归因于模块的表征贡献。这一发现直接驱动了本文的结构化替换设计（设计约束 D2）。

**(2) 组件移除干预（最终网络）。** 对训练完成的 SF-ConvNeXt 做推理期干预：将全部小波尺度 $\sigma_l$ 置零（WR 退化为预训练 7×7 基卷积）后，3 个种子 Macro-F1 变化 -0.21 / 0.00 / -0.18pt；将 $P_2,P_3$ 投影置零（CH 退化为仅 stage-4 头）后变化 -0.35 / -0.37 / 0.00pt。两组干预**方向一致为负、从不提升**，表明两个组件在推理期承载了真实（幅度适中）的判别贡献，同时其训练期梯度参与塑造了整个网络的共享权重——这正是结构化集成区别于可旁路门控的机制特征。

**(3) 错误结构分析。** 基线错误集中于良性↔恶性互混（每种子 15–24 例），正常类基本不混。最终模型最优 run 的混淆矩阵（§3.6）显示良性→恶性误报降至 6 例、恶性→良性漏诊降至 5 例，改善正落在临床最关键的边界上。
