# 第五轮预注册：训练目标与患者贡献对照

## 研究问题

四轮 72 次结构训练没有确认新增结构增益。第四轮同源全局基线 0.883140、标准 448 重训 0.880061、固定融合 0.885287、完整条件聚合 0.880436，所有差异患者区间跨零。继续枚举同类模块缺乏依据。

训练数据来自 185 个患者分组，单组 1–103 张，图像最多的 10 组占 667/2386≈28%。已有 A–E 是可学习性/标签一致性分级，并非临床纠错，且对困难 dysplasia 的降权更强。需要分开检验噪声适应、通用正则化与患者贡献，而不能从难样本错误直接推出标签噪声。

## 六组比较，只有十二次新增训练

全部为相同原始 ResNet34、原始 256/224 预处理、原 ImageNet 权重和配对分类头，种子 42/43/44，完整 val 538 张/39 组。保持 AdamW 1e-4、WD 0.05、batch32、60 epoch、余弦退火、AMP、原增强与完整验证集选择最佳 checkpoint。无新增推理模块。

| 组 | 训练方式 | 是否新训 |
|---|---|---|
| full_ce | 全量原标签普通 CE | 复用数据研究三个已完成模型 |
| grade_ce | 已冻结 A–E 等级加权 CE | 复用数据研究三个已完成模型 |
| label_smooth | 全量、固定均匀 label smoothing=0.1 | 三个新模型；通用正则化控制 |
| gce | 全量、不截断 GCE，q=0.7 | 三个新模型；低置信监督梯度调制 |
| elr | 全量、原 CE + 时间一致性 ELR，β=0.7、λ=3 | 三个新模型；原始标签仍用于 CE |
| patient_balance | 全量 CE，在每个原类别内均衡患者图像总贡献 | 三个新模型；分布控制 |

复用必须核对原任务签名、60 epoch、checkpoint SHA256及完整验证分数复现。等级加权验证逐图预测直接复用，原全量模型如尚无验证 CSV，仅用既有 checkpoint 生成完整验证预测。禁止重训有效完成的六个参考模型，也不读取它们的 test 预测。

所有新模型使用完整 2386 张训练图。GCE 不设样本剪枝阈值。ELR 以图像 index 维护仅训练时使用的 EMA，预测经 1e-4 截断并归一化后更新 target=0.7target+0.3p；target 不做初始偏差校正，与原实现相符。正则为 3·log(1−target·p)，原 CE 的监督标签保持不变。保存最后 60 epoch 的每图访问次数和 EMA 状态，明确它不是替换标签、临床正确概率或最终最佳 checkpoint 所需的推理状态。

患者平衡权重为 wᵢ=N_c/(G_c·n_gc)，N_c 是原类别图数、G_c 是该类出现的患者组数、n_gc 是该患者在该类的图数。每类平均权重严格为 1，每个患者×类别的权重总和相等。保留原类别总质量和全部难样本，报告权重范围与有效样本量；不把稀少患者自动当作更可靠。

## 实现与预检查

新增独立训练入口和损失文件，原四轮及 data_study 源码/config/manifest 不变。新循环沿用原优化/增强/选择逻辑，额外保留每批 index供 ELR 使用。验证 CE 工厂与原训练步在相同初始化、图像、AdamW、AMP下参数更新逐位一致，再复用原基线。

训练前检查 GCE 解析梯度与 q→0 的 CE 极限；ELR 与原公式的数值、EMA 只更新当前训练索引且不反传；真实训练图 AMP 损失/梯度有限；患者权重的类别总量与患者贡献约束；六个复用 checkpoint 和验证指标。标签平滑按固定公式正则化，不按模型预测生成替换类别；原数据文件、标签与 A–E 文件均保持不变。

每项训练与结果 Git 提交，并发 2、每进程 CPU 线程 2。完整训练已经有效完成、仅后续预测步骤失败时，复用签名及 SHA256 通过的模型，只重做缺失预测。ELR 状态另存 SHA256；每张训练图必须正好访问 60 次，验证/test 不得进入 EMA。

## 分析与后续判据

主要指标仍为完整验证集 macro-F1，并报告恶性 F1/召回、各患者等权平均准确率、三个种子的全部结果与 20,000 次患者配对 bootstrap 区间。所有方法对 full_ce、grade_ce 比较，GCE/ELR/患者平衡另对通用 label_smooth 比较。不同目标的 train_loss 数值不能直接横向比较，另记原 CE。

强信号：相对 full_ce 三种子均正、均值至少 +1.0 个百分点且患者区间下界正；相对 grade_ce 均值至少 +0.5 个百分点且区间下界正。若要将 GCE/ELR 的效果归因于噪声适应，还需超过 label_smooth 至少 +0.5 个百分点且区间下界正。即便满足，也只是独立确认的候选，不证明哪些标签错了。若仅平滑或患者平衡有效，应按通用正则化或患者分布解释，不包装为噪声纠错或新网络贡献。

完整开发集被多次使用，区间条件于已拟合模型，没有校正选择/多重比较；任何晋级均需独立患者确认、数据×结构交叉及公平原模块/预算对照。严格外层 CV 时，等级必须在外层训练内部重新计算或由真正独立分级器提供。本轮不筛 val/test、不修改标签、不按 test 调参、不评估 test。后续结构只建立在明确的数据/训练证据上，而不是继续无限枚举模块。
