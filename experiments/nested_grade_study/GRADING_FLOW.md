# 第十四阶段：严格嵌套的自动分级对照

```mermaid
flowchart TD
    A[原 train：2386图 / 185患者组] --> B[复用原3seed × 5外折]
    B --> F[fit患者]
    B --> I[inner患者：只选学生checkpoint]
    B --> O[outer患者：最终完整评分]
    P[公开预训练冻结DINO特征] --> G
    F --> G[fit内部：3次患者5折线性分级]
    G --> Q[每张fit图3次患者留出预测]
    Q --> E[原A–E阈值：现有标签一致性代理]
    E --> W[等级加权 / 同类内打乱相同权重]
    E --> C[A–C筛选 / 同类等数量随机筛选]
    W --> S[同食谱普通ResNet34]
    C --> S
    I --> S
    S --> O
    R[复用15个原 full CE OOF基线] --> T[完整OOF配对比较]
    O --> T
```

inner与outer患者不进入分级头拟合、标准化或分级。outer始终完整评分，不按等级筛掉困难图。

225次凸线性分级拟合不是225次神经训练。新增学生CNN最多60个，另复用15个基线；精确相同的有效训练配置会复用模型并记录别名。

预先指定主比较：等级加权相对完整CE、相对打乱权重。次比较：A–C相对完整CE、相对同类等数量随机筛选。每个方法必须同时通过两项三种子正差、平均至少1pt、四比较家族区间下界正的标准。

这检验所定义的自动分级是否有助于患者泛化，不能把分级当临床质量金标准或证明标签错误。仍为同185患者内部研究，不是外部独立确认。
