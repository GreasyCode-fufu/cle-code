## 4. 噪声机理诊断（决定新主线的关键证据）
1. **决策面漂移而非排序退化**（全部 run 的 predictions.csv）: AUC_BM 0.975–0.993 各 run 稳定; 塌陷 run 的 test 最优 B/M 阈值
   −1.5 ~ −6.1（baseline s44 −6.1）, 错误集中为 **异型增生/癌 → 良性**（star3 s44: 异型增生→B 22、癌→B 12）。
2. **非亮度捷径**: 错判为 B 的 M 帧亮度仅高 0.005（类间差 0.046）; 但 val 的 M 帧整体偏亮（0.334 vs train/test 0.307/0.309）——
   val 上选点所依据的 M 群体与 test 分布不同。
3. **选点 = 未退火轨迹上的噪声峰**: best epoch 27–76, 此时 lr 仍为峰值 85–98%; val F1 逐 epoch 波动 1.3–1.8 点, 所选 best
   比局部均值高 ~2 点（winner's curse）。
4. **精确 BN 重估反而大降**（−3.2 F1, sens_M −10~15）: BN 统计量强烈调制 B/M 决策面, 印证 train/test 特征分布偏移。
5. **事后 logit adjustment（τ·log π, τ 不在 test 上调）** 仅小幅改善（+0.25~0.65）, 不能修复塌陷 → 弃用。
6. **池化方式**（`r6_p0b_pooling.py`）: GeM/max 更差; FOV 掩码 GAP 只在**冻结的 ImageNet 特征**上有益（f12 +1.2 F1）。
7. **扩展空间读取**（线性瓶颈理论）: 探针 +0.4 F1, 但端到端 star2x −1.07（5 seeds）→ 否决。
