# R3 轮设计文档 — SF-ConvNeXt 继续优化（2026-11-08 会话）

## 0. 目标与基准（用户确认）

- 基准：**同批重跑**的 convnext_tiny（Batch CA，3 seeds，seed 42/43/44，本批权重根 weights_cle_ac_v1_c）。
- 成功线：最终网络（2–3 个创新点整体）在 test 上任一 evaluate.py 指标 3-seed 均值 **≥ +1.5pt**。
- 起点：SF-ConvNeXt = WR(WTConv 替换 stage-3/4 dwconv) + CH(三尺度拼接分类头)，同批复验其真实增量
  （历史同批口径仅 F1 +0.31pp / Kappa +0.43pp，这是本轮必须正视的起点）。
- 链式规则：创新点逐个叠加，A 有效保留，B 在 A 基础上叠加。
- 泛化：达标后在 CUB200 / covid_v1 / heelBone / BUSI / TCGA 上与 baseline 同批 3-seed 对照，如实报告。

## 1. 证据汇总（决定设计方向）

1. 历史规律（187 条 ok 记录）：**任何第三模块叠加到 v2bc 上几乎都回退**（EPNet/FD 轮全部组合 < 最佳单件）；
   头部类改动（DPH/CMP/AEP）单件尚可、叠加必回退；频域算子家族（WR/FGC/FESR）同批增量 +0.3~0.9。
2. 数据分析（本轮，全量 3080 张）：B-vs-M 低层统计 AUC≤0.66 → 判别信号在**结构规则性/局部异质性**；
   暗像素 25–31%（p01 完美区分 N，即暗区是强先验）；方向各向同性；频谱能量类杠杆已尽。
3. 错误结构（SF 最优 run，19/576）：atrophy→M 6、N→B 6、M→B 5；test 中 20 张 atrophy 帧标为 M、
   val 存在交叉亚型标注 → 存在不可约误差底，Macro 指标天花板 ~0.97。
4. 姊妹项目已占用创新（不可复用）：FGC 频域全局卷积、DSD 方向条带、SVD 低秩 MLP、EGB/SCG/HSC、
   SN 谱归一化、OCA 条带上下文、WN、DPH/CMP/AEP 池化头、AMH/MFM 训练辅助。

## 2. 本轮候选创新点（Batch CB 快筛，全部：替换式/不可旁路/严格加载审计/预训练兼容）

### 候选 1：全深度小波替换 FWR — `convnext_v3f`（WR 推广 + CH）
WR 只替换 stage-3/4；stage-1/2（56²/28² 分辨率，腺体尺度所在层）从未在 V2 替换语义下测过。
V1 时代 "s234 更差" 的结论来自可旁路的并联门控（不可信）。v3f 将 WTConv 替换推广到全部 4 个 stage
（stage-1/2 同样经 _remap_wr 继承预训练 dwconv 权重），腺体尺度（224 下 ~10–20px）落入 stage-1/2 的
小波子带卷积感受野。零新增设计，纯推广，成本最低。

### 候选 2：二阶纹理池化头 SOP — `convnext_v3s`（WR@s34 + SOP，CH 的升级）
理论依据直击数据分析结论：**纹理=特征共现**。CH 的一阶 GAP 只保留每通道均值，丢弃通道共现结构
（腺体排列规则性=特定通道响应的空间/通道联合分布）。SOP 对三个尺度特征各做：1×1 投影到 d=64 →
去均值 → 协方差矩阵 C=XᵀX/N → Newton-Schulz 矩阵幂归一化（iSQRT-COV 风格，参数 free，fp32 计算）→
flatten 拼接 → 与一阶 GAP 拼接向量共同送入分类器（保留 CH 已验证的一阶通路，二阶为增强项，整体仍
不可旁路：头结构改变，必须消费二阶证据）。参数 +~0.13M。二阶池化家族在本项目族从未尝试。
风险：小 batch 下协方差估计噪声（bs=32、s4 仅 49 token → d=64>49 秩亏，靠 NS 归一化 + εI 正则）。

### 候选 3：自上而下语义门控精炼 XRM — `convnext_v3x`（WR@s34 + CH + XRM）
CH 把三尺度证据"拼"给分类器，但 s2/s3 特征未经深层语义调制。XRM 在池化前用 s4 全局语义向量对
s2/s3 特征做**乘性通道门控**：f' = f ⊙ (1+tanh(W·g₄))，纯乘法、无加性恒等旁路（与被证伪的零门控
并联注入本质不同：门控作用于被消费路径本身）。g₄ 经 stop-gradient？不——允许梯度回传（端到端）。
类比 top-down attention（FPN 系），但在分类头前、且乘性不可旁路。

### 候选 4：腺体环尺度扩张卷积 DRC — `convnext_v3r`（WR@s34 + CH + DRC@stage-2）
腺体在 224² 下直径 ~10–20px，stage-2（28²）单块 7×7 dwconv 感受野不足一个腺体簇。DRC 替换 stage-2
dwconv 为 "预训练 k7 基分支 + 双膨胀（d=3/d=6）k3 子带分支"（结构与 WR 的 base+扩展同构，尺度初始
0.1，预训练经重映射继承）。stage-2 是前作未触碰区，DSD(条带)在该位单件 +0.35 证明位置有增益空间，
DRC 换成非方向的尺度扩张（数据分析：方向各向同性 → 尺度先验优于方向先验）。

### 探针（非创新点，只是廉价对照）：v2bc + class-weights(1,1.25,1) / v2bc + label-smoothing 0.05
用于确认训练级杠杆是否值得并入最终协议。

## 3. 实验计划

- Batch CB（快筛）：CB1 v3f / CB2 v3s / CB3 v3x / CB4 v3r 各 2 seeds（42/43），并发 4，~30min。
  判定：同 seed 配对优于 v2bc（CA 批）且不劣于自身方差者入选。
- 叠加轮：入选者两两/三叠加（链式，A 有效保留），3 seeds。
- 达标后补 seeds 45/46 复验 → 泛化五域（与各域 convnext_tiny 同批 3 seeds）。
- 每批 git 提交；全部结果落 results_cle_ac_v1_c.csv（C 轮统一口径）。
