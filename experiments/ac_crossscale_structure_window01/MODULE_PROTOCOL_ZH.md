# CLE跨尺度对应统计：冻结正式轮

保留原M轮方向矩工作结构，原固定B0保持不变。P细化轮12模型已完成审计：标准差较mean_only单视图三seed均好，均值0.8398百分点、条件区间正；随机空间核对照只在C4推理有正向差证据，单视图区间跨0。ECA累计及额外旋转增强未稳定改善，不保留为确认有效组件。本轮从同公开ImageNet权重重新训练全部新arm，复用原B0和M方向矩有效对照，不热启动已训练checkpoint。

机制假设：CLE为重复局部纹理且组织边界可能随方向变化，浅层局部纹理与深层组织表征的空间对应关系可能包含全局平均丢失的信息。方向矩处理stem的方向响应离散度，跨stage3/4相关描述空间配对，作用位置和统计对象不同。是否互补需累计和去一重训，不能从机制描述推导效果。

ConvNeXt-Tiny224取stage3末384×14×14和stage4末768×7×7；前者2×2平均对齐7×7；各1×1无偏投影rank16。沿49位置各通道居中、除sqrt(方差+1e-4)，跨层16×16互相关展平d，输出16d/sqrt(1+||d||²)。FP32统计，double数值check保留double。描述子范数<16；固定scale16=√256使非退化描述子每维RMS接近1，与原LN的通道尺度一致。它是几何尺度选择，没有使用val/test分数搜索；不静改旧CPU原型（旧原型scale1保持冻结）。零初始化256→3残差头保证公开初始化logit逐位一致；第二次实际梯度步骤需确认投影获得非零梯度。

四arm×seed45/46/47，共12项：mom_corr=方向矩+真实居中相关；corr_only=去方向矩，检验累计贡献；mom_shuffle=相同参数/投影/尺度但只打乱深层49位置的固定可复现排列，检验空间对应；mom_bilinear=方向矩+成熟B-CNN未经居中二阶乘积、signed-root+L2参照。后三个保留全部阴性，不无限枚举近似组合。真实与打乱同参数；去方向矩少18528；全新readout19203参数。全部same optimizer LR groups和60epoch，不能只选最好seed。

训练仅固定2077/182患者train、原val427/39最早最高macroF1选权重；batch32，原encoder1e-5、新方向矩/投影/头1e-4、AdamW.05、cosine0、clip1、AMP、workers2、CPU线程1。原H/V、rotation15，全部相同。每epoch实际2077唯一索引及SHA，不改变原3595物理cache或A–C清单/标签/等级。患者互斥，恶性id1。新结构源码/配置/tasks/数值预检查先Git提交，CPU/CUDA数值有限/随机性/完整基准概率复现通过后训练。

用户明确test反馈下一设计，故每个完整三seed方法在同checkpoint上报告单视图和C4，不能以test选择本次epoch。历史test被查看且AC构建用过其标签，所有选择均为自适应内部开发。macroF1主指标，accuracy/恶性召回/患者等权accuracy/逐seed混淆矩阵/预算全报。共享41患者20k配对bootstrap，只作条件不确定性，不校正反复筛选偏差；不能称独立泛化/外部验证。主门槛平均Δ严格>0.015、全部seed正、条件区间下界>0；成立时再独立Fraction整数混淆矩阵复算。对固定B0、B0C4、DINOC4、SwinC4和原方向矩同模式均比较，四倍推理成本披露。

实际batch32两次AMP更新同时记录train/val描述子幅度、残差logit和投影/头梯度，不看test、不搜索分数；失效先修数值实现并保留v1，不能将无梯度分支当阴性研究。独立测1/2/4并发吞吐/显存/CPU/I/O/等待，best97%最少并发、保留6GiB余量，实测不足且收益增才扩大。有效任务GPU尽量长期80%以上，不为填GPU造任务。正式阶段另独立只读采样覆盖同步审计间隙；profile/perEpoch资源保持。
